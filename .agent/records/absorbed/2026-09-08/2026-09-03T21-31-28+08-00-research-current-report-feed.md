# 研究列表接入当前公司研究

时间：2026-09-03T21:31:28+08:00 Asia/Shanghai

## 目标

让 `/research/` 展示当前公司研究 Agent 的合格产出，例如中国能建，而不再只展示旧版注册表深度研报。

## 实现

- 新增研究列表聚合层，同时读取 `stock-research-analysis-v2` 当前报告和注册表正式报告。
- 当前报告继续使用五项 Sol 自审、关键字段和正文存在性准入，不新增旁路。
- 同一证券、同一报告期重复时，当前协议覆盖列表中的旧版条目；旧版不可变文章仍生成并保留原地址。
- 当前报告卡片链接到 `/reports/<code>/`，注册表报告仍链接到 `/research/<code>/<version>/`。
- 列表按来源仓提交时间倒序；非 Git 测试输入回退到报告信息截止时间，再回退到报告期。
- `data/research.json` 改为输出统一列表，并标注来源和协议版本。

## 验证

- `python3 -m unittest discover -s tests -v`：11 项通过。
- 使用包含四份当前协议报告和七份注册表报告的干净 `stock_report` 工作树构建，去重后共 10 条。
- 中国能建位列第一，日期为 2026-09-03，链接为 `../reports/601868.SH/`。
- 页面不恢复旧宣传页头，旧版正式文章地址仍完整生成。
