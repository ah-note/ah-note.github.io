# 行业分类入口与发布器热更新闭环

时间：2026-09-07 22:06:09 +08:00

## 任务

为 AH Note 的行业分类页补齐稳定、可见的站点入口，并修复常驻自动发布器使用旧内存模板覆盖新导航的问题。

## 结论

- 首页、报告、研究和参考页顶部导航统一加入“行业”，指向`/industries/`。
- 根因不是行业页缺失，而是远端常驻 Python 发布器在 Git 快进后仍继续使用启动时加载的旧模板。
- 发布器现在会在实际发布前检查干净工作树并快进站点仓；如 HEAD 变化，则通过`exec`自重启，保留原参数并在下一轮用新代码生成页面。
- 增加回归测试，确认站点提交变化时触发进程重载。

## 验证

- Python 单元测试覆盖发布器重载逻辑和现有站点流水线。
- 校验 Python、JavaScript 语法及 Git diff 格式。
- 提交后由远端服务器拉取更新并重启发布服务，再检查线上入口。
