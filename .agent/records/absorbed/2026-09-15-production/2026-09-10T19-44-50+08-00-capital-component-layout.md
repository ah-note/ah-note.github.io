# 资本表构成展开布局修复

时间：2026-09-10T19:44:50+08:00

## 问题

多年资本表点击“经营周转净额”后，构成明细以嵌套表格放在首列单元格内。多年度列被压缩到约230px宽的首列中，造成行高、列宽和后续余额列视觉错位。

## 处理

- 构成标题改为同页展开按钮。
- 构成项改为父表共享子行，使用各年度余额列显示对应值。
- 某年度变动区展开时，构成子行在该两列区域使用跨列空位，保证后续年度余额继续对齐。
- 页面本地CSS和JS使用统一版本参数，避免缓存导致新HTML/渲染器与旧事件脚本混用。
- 增加真实父表行结构测试，禁止重新出现嵌套构成表。

## 验证

- `node tests/test_capital_annual.js`：6项通过。
- `node tests/test_tan_compare.js`：9项通过。
- `python3 -m unittest discover -s tests -v`：34项通过。
- `git diff --check`：通过。
- Chrome真实加载2021—2025页面，展开“经营周转净额”后11个构成项逐年对齐；再同时展开2024年度变动，表格列结构仍保持一致。
