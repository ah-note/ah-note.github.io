湖南黄金（002155.SZ）2025年度经营质量与控股回本研究

研究基准日为2026年7月31日，财务期为2025年12月31日。市值采用输入快照359.25亿元，PE TTM 20.51倍。核心财务事实来自经天健会计师事务所标准无保留审计的2025年年度报告全文。本文不构成买卖建议。

先说结论

湖南黄金是普通经营型矿业公司，普通控股回本框架适用；但必须把“自产金锑钨矿山”与“大规模外购非标金加工”拆开。2025年收入501.81亿元、增长80.26%，其中443.52亿元来自毛利率仅0.08%的外购非标金。真正创造利润的是矿山采选：该板块收入43.69亿元、毛利率67.61%。因此收入规模和增速显著高估了生意的经济体量。

2025年归母净利润14.88亿元，经营现金流14.99亿元，减3.25亿元长期资产购建支出后，经营自由现金流11.73亿元，利润当年基本变成了现金。不过金属价格处于有利阶段，自产黄金和锑分别下降7.40%和6.71%，不能机械外推单年利润。

按保守控股口径，折后可剥离净现金约11.37亿元，只占市值3.16%；折后可持续现金利润约7.62亿元。扣现金后的经营业务价格347.88亿元，对应约45.7年回本，市值/现金利润约47.2倍。它比输入PE TTM 20.51倍严格得多，主要因为采用两年自由现金流均值并对周期性再打折。

公司怎么赚钱

公司开采以金锑（钨）伴生矿、金矿、锑矿和钨矿为主，井下采矿后通过重选、浮选、冶炼分离和精炼，形成标准金锭、精锑、含量锑、氧化锑、乙二醇锑和钨精矿。标准黄金通过上海黄金交易所按当日市场价销售；锑钨产品主要卖给下游生产企业及贸易商。公司盈利依赖资源品位、回收率、采选冶技术、单位成本和金属价格，而不是品牌溢价。

2025年共生产黄金61,382千克，但自产黄金只有3,431千克，其余主要体现外购原料加工；自产黄金同比下降7.40%。公司自产锑14,206吨，同比下降6.71%，自产钨精矿908标吨，同比增长3.30%。这解释了为什么501.81亿元收入不能视作等量的矿山经济产出。

公司披露自身为全国十大产金企业和全球锑矿开发龙头，拥有100吨/年黄金、2.5万吨/年精锑冶炼、4万吨/年多品种锑生产线。行业位置来自公司年报陈述；其经济含义是具有完整采选冶链条和锑钨出口资质，但产品价格主要由市场决定。

综合毛利率从上年下降1.71个百分点，并不等于核心矿山盈利恶化：外购非标金占比升至88.38%，其毛利率只有0.08%，结构变化天然压低综合毛利率。与此同时，有色金属开采毛利率67.61%，同比上升8.77个百分点。观察经营质量时，应优先跟踪自产金锑钨产量、品位、单位成本和开采板块毛利，而非总收入。

资产负债对应什么

期末总资产94.36亿元、总负债12.71亿元、归母权益81.17亿元，短期借款和长期借款均为零，少数股东权益仅0.48亿元，财务杠杆很低。

资产端，货币资金20.07亿元，其中现金及现金等价物19.16亿元；应收款项融资4.07亿元，主要是结算性票据。存货9.69亿元是原料、在产品和产成品，锑品库存6,185吨、同比增加65.29%，既占用资金也暴露于锑价波动。固定资产36.38亿元主要是矿山井巷及选冶设施。无形资产7.60亿元和长期待摊费用11.91亿元代表矿权、资源与勘探投入；长期待摊中地质勘探支出11.38亿元，其价值取决于最终可采储量、品位和价格，不能当成可变现投资资产。

负债端主要是经营负债：应付账款、合同负债、职工薪酬、税费和其他应付款。债务及租赁类负债合计仅0.24亿元。预计负债1.29亿元包含矿山恢复治理等随开采而来的长期义务。因此账面现金虽然明显高于有息负债，也不能全部从企业拿走。

利润能否分配

2025年经营现金流与归母利润相当，扣资本开支后仍有11.73亿元自由现金流，单年现金转化良好。母公司期末未分配利润14.31亿元，也具备法律层面的分配基础。董事会年报预案为每10股派3元，合计4.69亿元，占2025年归母净利润约31.5%；相对输入市值的预测分红率约1.30%，最终以批准及实施公告为准。

历史现金分红金额为：2022年1.20亿元、2023年1.56亿元、2024年2.76亿元。分红持续增长，但资源公司的可分配能力仍受金属价格、自产量、勘探开发投入及重大资产交易资金需求影响。

控股回本计算

折后净现金不是“货币资金减借款”。现金及现金等价物19.16亿元按50%计入，应收款项融资4.07亿元按50%计入，再全额扣除0.24亿元债务及租赁类负债，得到11.37亿元。50%折扣用于保留矿业营运资金、维持性资本开支和资源投入，不是公司披露数字，而是保守判断。

可持续现金利润以2024、2025年经营自由现金流5.19亿元和11.73亿元的平均值8.46亿元为基础，再因金属价格周期、自产黄金下降及外购金低毛利结构打九折，得到7.62亿元。

经营业务购买价 = 359.25 - 11.37 = 347.88亿元
控股回本年 = 347.88 / 7.62 = 45.7年
市值/现金利润 = 359.25 / 7.62 = 47.2倍

这不是对未来利润的确定预测。若高金价长期维持、自有矿产量与品位改善，口径会显得过于保守；若价格回落、品位下降或资本开支上升，则7.62亿元仍可能偏高。

什么可能推翻判断

  • 金锑钨价格是利润最直接的外部变量。2025业绩受价格上涨推动，周期反转会降低矿山毛利与现金流。
  • 自产黄金和锑已经下降，资源接续、品位和采选回收率决定高毛利矿山板块能否持续。
  • 锑品库存同比上升65.29%，可能带来营运资金占用和跌价风险。
  • 公司在研究时点推进控股股东黄金资源相关重大资产重组；交易估值、融资、股份摊薄和现金用途可能改变当前资产与盈利基数。

数据边界

财报数字取自公司2025年年报；市值和PE沿用输入中的Tencent快照，未另行以交易所逐笔行情复核。现金折扣、利润周期折扣及回本年属于研究推断，事实与判断已分别标明。
