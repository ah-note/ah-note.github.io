Value Line, Inc.（VALU）经营质量与控股回本研究

本次研究归档期为 2025-12-31，但 Value Line 的财年截止日是 4 月 30 日，因此年度财务分析使用截至 2025-04-30 的 FY2025 Form 10-K；分红运行率与基金管理规模的趋势补充使用截至 2026-01-31 的 10-Q。输入市值为 21.66 亿元人民币（2026-08-03），PE TTM 为 14.87 倍。为满足统一结果协议，美元财报金额按分析汇率 7.20 人民币/美元换算。

公司怎么赚钱

Value Line 有两层生意。

第一层是公司直接经营的投资研究出版业务：向个人和机构出售纸质、数字投资期刊和相关研究订阅，也把 Value Line 商标、专有排名和研究数据授权给第三方基金、ETF、年金等产品使用。订阅通常预付，公司在服务期内逐步确认收入；版权费则随使用相关知识产权的第三方产品资产规模变化。

第二层是对 EULAV Asset Management（EAM）的合同收益权。EAM 管理和分销 Value Line 共同基金，公司没有 EAM 的投票控制权，却有权取得其调整后总收入的 41%—55%，另取得 50% 利润；收入权及至少 90% 的利润权通常按季分配。这不是普通证券投资，而是 Value Line 品牌、排名体系和历史基金业务拆分后保留下来的核心经营收益权。FY2025 10-K

因此，报表上“出版经营利润”不能代表完整盈利能力。FY2025 出版经营利润只有 598.5 万美元，但 EAM 收入权与利润权合计贡献 1,831.8 万美元，才是归母利润和可分配现金的主要来源。

经营数据说明什么

FY2025 出版收入为 3,507.9 万美元，同比下降 6.4%；其中投资期刊及相关出版物下降 2.9%，版权费下降 13.8%。出版收入已连续两年下降，说明传统订阅、版权产品规模和线上免费/低价研究竞争仍在侵蚀本体业务。同期广告推广费上升，出版经营利润由 914.1 万美元降至 598.5 万美元，利润降幅明显大于收入降幅。

公司没有披露 GAAP 销售成本或毛利。本研究为了协议展示，将生产与分销费用 598.7 万美元作为直接成本代理，得到代理毛利 2,909.2 万美元、代理毛利率 82.9%。这个高比例主要说明研究与版权业务不需要大量实物投入；编辑、分析人员薪酬计入期间费用，因此它不能与制造企业毛利率直接比较。

FY2025 净利润为 2,068.6 万美元，净利率达到 59.0%。高净利率并非出版业务突然变强，而是 EAM 两项收益权贡献增加，以及 323.8 万美元投资收益共同作用。EAM 管理/分销的 Value Line 基金资产在 FY2025 末为 46.8 亿美元，同比增长 12%；但截至 2026-01-31 已降至 42.0 亿美元，同比下降 15.5%，说明这条核心现金流会随市场、基金表现和申赎变化。FY2026 Q3 10-Q

资产负债对应哪些真实东西

截至 FY2025 末，总资产 1.445 亿美元，总负债 4,485.5 万美元，股东权益 9,967.8 万美元，没有少数股东权益。

流动资金很充裕：现金及现金等价物 3,407.7 万美元，其中大部分是短期美国政府货币市场投资；美国政府债和少量银行存单等固定收益证券 2,243.5 万美元；股息 ETF 等权益证券 2,087.9 万美元。这三项合计 7,739.1 万美元，具有较高变现能力，但权益证券仍有价格波动，不能按账面值无折扣扣减市值。

最大的长期资产是 EAM 权益法投资 6,080.7 万美元。它对应持续收入和利润分配权，是生意的一部分，不应既把未来 EAM 分配计入现金利润，又把整项投资当作可以拿走的净现金，否则会重复计算价值。其余物业设备、软件、应收和预付项目规模较小，符合轻资产研究出版业务特征。

负债端最重要的是 2,229.0 万美元递延订阅收入。这是客户已经付款、公司未来仍需交付内容的经营义务，并非有息债务，也说明订阅模式可带来预收现金。租赁负债为 357.9 万美元，对应办公场所；应付股利 305.9 万美元已经承诺流出，在可剥离现金中全额扣除；另有 1,319.5 万美元递延所得税负债。

利润能否变成可分配现金

FY2025 经营现金流为 2,024.3 万美元，与净利润 2,068.6 万美元接近。设备购置和资本化软件支出合计仅 23.7 万美元，因此经营自由现金流约 2,000.6 万美元。EAM 当年实际收到的收入分配和利润分配合计 1,764.5 万美元，也与确认收益较为接近，利润并没有大量停留在权益法账面上。

公司当年支付现金股利 1,130.3 万美元并回购 45.3 万美元，合计约占自由现金流 58.8%；现金创造覆盖了实际股东分配。最近披露的季度股利运行率为每股 0.325 美元，按每年 1.30 美元、2026-02-28 流通股数和统一汇率估算，年度现金股利约 8,786 万元，对输入市值的预测股息率约 4.06%。这是运行率推算，不是董事会承诺。

控股回本口径

公司虽然属于投资研究和基金管理相关行业，但合并报表没有客户存款、客户交易资金或匹配金融负债；EAM 也没有被合并。因而普通经营公司控股回本模型适用，关键是把 EAM 收益权保留在经营业务中。

可剥离资产按以下方式折价：现金按 100%，固定收益证券按 95%，权益证券按 70%，再扣除已宣告的应付股利。得到折后可剥离净现金约 4.82 亿元，占输入市值 22.3%。这里没有扣除正常递延收入和其他经营负债，因为业务继续经营时它们由日常履约和营运资金承接；若按清算而非持续经营视角，折扣应更严。

FY2025 自由现金流为 1.440 亿元人民币。本研究将可持续可分配现金利润下调并取整为 1.296 亿元（1,800 万美元），较当年自由现金流折减约 10%，用于覆盖证券收益波动、出版收入下滑和 EAM 分配波动。它不是对未来利润的精确预测。

由此：

  • 经营业务隐含购买价 = 21.66 亿元市值 − 4.82 亿元折后净现金 = 16.84 亿元；
  • 控股回本年 = 16.84 亿元 ÷ 1.296 亿元 = 约 13.0 年；
  • 不扣现金的市值/现金利润 = 约 16.7 倍。

这个结果的经济含义是：若可剥离证券能按上述折扣变现，且出版业务与 EAM 合计每年长期产生约 1,800 万美元可分配现金，控股经营资产约需 13 年回收购买价。它没有计入增长，也没有给终值；同时不是买卖建议或收益保证。

哪些事实可能推翻判断

最关键的是 EAM：其 FY2025 两项收益已经远高于出版经营利润。基金资产规模继续下降、投资表现落后、基金合同终止或费率下降，都会直接削弱可持续现金利润。其次，出版收入和版权费均在下滑；若数字业务不能抵消传统渠道衰退，当前轻资本模式仍可能出现经营杠杆向下。

现金折扣也不是无条件成立。权益证券可能下跌，公司可能出于运营或税务原因保留更多资金；91.74% 投票权由 AB&Co. 控制，外部股东无法决定是否剥离资产或提高分红，且公众流通股比例低会限制交易流动性。若可剥离现金减少 1 亿元，其他假设不变，回本期会增加约 0.8 年；若可持续现金利润比基准低 20%，回本期会升至约 16.2 年。

结论边界

Value Line 的真实经营故事不是单纯的衰退型纸质出版商，而是“缓慢收缩的研究订阅/版权业务 + 高分配率的 EAM 合同收益权 + 大量流动证券”。它资本开支极低、FY2025 利润转现金良好并能覆盖分红，但盈利集中于受市场和基金申赎影响的 EAM，传统出版收入仍在下降。按本报告明确的折扣和正常化假设，普通控股回本约 13.0 年；判断是否成立，应持续跟踪 EAM 资产规模及分配、出版收入降幅和实际股利，而不能只看 14.87 倍 PE。
