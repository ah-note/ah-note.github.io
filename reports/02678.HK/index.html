天虹国际集团有限公司（02678.HK）2025年度研究

本报告基于截至2025年12月31日的经审计年报，行情估值采用输入所给腾讯快照：2026年8月3日市值51.94亿元、PE TTM 5.97。所有财务金额均为人民币。本文不构成买卖建议；“回本年”只是静态控股口径估算。

先纠正财报模型

输入把公司提示为券商模型，但这与财报事实不符。天虹国际制造并销售纱线、坯布、梭织及针织面料和无纺布，核心资产是纺纱织造设备、存货和应收款，负债主要是银行借款、供应链融资及经营应付款，不存在券商客户资金、自营金融资产或卖出回购业务。因此本次覆盖输入提示，采用普通经营公司模型，普通控股回本口径适用。

公司怎么赚钱

公司是一家资本密集型棉纺制造商。它采购棉花等原料，在中国、越南、土耳其及美洲的工厂完成纺纱、织造和染整，再按合同价格向全球5,000多家客户销售。2025年底的主要产能约为426万纱锭和逾1,700台织机。

2025年收入227.16亿元，其中纱线181.09亿元，占约79.7%，是绝对核心；梭织面料21.98亿元，贸易15.71亿元，其余针织面料、坯布、无纺布及公用事业收入规模较小。利润的本质是棉花等原料成本与纱线、面料售价之间的制造价差，包芯纱等较高附加值产品、规模化生产和跨国布局是公司争取毛利的主要手段。

公司在年报中称自己是全球最大的棉纺织品制造商之一，并是领先的高附加值包芯纺织产品企业。这个行业位置有产能和客户覆盖作支撑，但本次没有取得行业协会的同口径全球排名，因此应视为公司自述，而非独立排名结论。

2025年经营数据说明什么

收入同比下降1.4%至227.16亿元，但毛利同比增长9.6%至31.38亿元，毛利率由约12.43%升至13.81%。这说明2025年的改善主要来自单位价差和成本结构，而不是销量或收入扩张。扣除销售及分销开支6.40亿元、行政开支11.26亿元、金融资产减值及其他净损失后，经营利润为13.84亿元；再扣除净融资成本1.66亿元和所得税2.50亿元，归母净利润为9.13亿元，净利率4.02%。纺织制造的利润缓冲仍然不厚。

经营现金流43.04亿元，减去购买厂房设备12.27亿元，经营自由现金流为30.78亿元，远高于归母利润。这是好现金流，但不宜直接作为永续水平：现金生成包含应付贸易及票据增加17.79亿元、合同负债增加1.58亿元等营运资金释放。2025年存货周转85天、应收贸易及票据27天，均较2024年略有改善；强现金流同时帮助借款和供应链融资下降。

资产负债对应什么真实东西

总资产202.47亿元，核心生产性长期资产约93.49亿元，包括土地、厂房设备、投资物业、使用权资产及无形资产。这些资产对应纺锭、织机和染整产线，是维持收入的经营底座，不能从市值中当现金扣除。

存货47.45亿元、发展中物业3.59亿元，合计51.03亿元。存货约占总资产23.4%，主要对应棉花、在产品和纱线面料成品，因此棉价、需求和减值会同时影响毛利及资产质量。应收贸易及票据13.21亿元，另有预付款、其他应收款和应收类金融资产，主要是销售与采购周转占用。

现金及等价物24.88亿元、抵押存款0.08亿元，合计24.95亿元。负债端有借款53.82亿元、供应链融资17.90亿元和租赁负债1.44亿元，融资性负债合计约73.16亿元，显著高于现金。另有应付贸易及票据9.25亿元、合同负债3.90亿元及其他经营和税务负债。由此看，账面现金首先服务于营运和偿债，不是控股股东可以无约束拿走的可剥离现金。

利润能否变成可分配现金

2025年利润确实变成了现金，且现金转化很强；但“有现金流”不等于“可立即分配”。公司融资性净负债约48.20亿元，董事会也明确把进一步降债、降低融资成本和主动市场扩张作为2025年不派中期及末期股息的理由。故本次预测现金分红取0，预测股息率为0%。这是依据已经宣布的2025年度分配，而不是断言以后永不分红。

现金利润从归母净利润9.13亿元出发。2025年资本开支12.27亿元，而折旧、摊销及减值为11.16亿元，两者差额1.11亿元从利润中扣除，得到8.02亿元；再打九折，反映棉价、汇率、贸易环境及行业周期，折后可持续现金利润为7.22亿元。由于年报没有拆分维护性与扩张性资本开支，这一算法是审慎近似，不是精确的长期自由现金流预测。

控股回本口径

现金类资产低于融资性负债，因此折后可剥离净现金取0。经营业务购买价等于全部市值51.94亿元：

折后可剥离净现金 = 0
折后可持续现金利润 = 7.22亿元
经营业务购买价 = 51.94亿元 - 0 = 51.94亿元
静态控股回本年 = 51.94亿元 / 7.22亿元 = 约7.20年
市值 / 现金利润 = 约7.20倍

这个结果表明当前市值相对于本次折后现金利润的静态倍数不高，但不能脱离资产负债表理解：股东买到的是一个仍有净债务、需要持续投入设备和营运资金、利润受棉纺周期影响的经营体，而不是“市值减大额净现金”的轻资产公司。PE TTM 5.97与上述回本倍数不同，主要因为回本口径额外扣除了资本开支超过折旧的部分并做了周期折扣。

哪些事实会推翻结论

  • 棉价和产品售价不能同步传导，会压缩本来只有13.81%的毛利率；47.45亿元存货也会放大价格及减值影响。
  • 若2025年营运资金释放不可重复，经营自由现金流将明显低于30.78亿元，不能用单年自由现金流推导极短回本期。
  • 若实际维护性资本开支长期显著高于本次近似，7.22亿元现金利润会被高估；反之，若12.27亿元包含较多扩张投入，本次估算可能偏保守。
  • 跨中国、东南亚、美洲等地生产销售带来关税、贸易政策及美元、港元、越南盾等汇率风险。
  • 净负债下降是分红恢复的重要前提。若公司继续把现金用于扩张或债务服务，账面盈利未必在短期转为股东现金回报。

数据质量
