长虹美菱 2025 年股票研究报告

长虹美菱进榜的原因不是利润特别便宜，而是折后可剥离净现金68.62亿元高于粗筛市值50.05亿元，经营业务购买价为-18.57亿元。便宜主要来自现金、定存、大额存单和部分投资资产的净现金覆盖，不来自主业高回报；扣掉这些资产后，对应利息和投资收益不能再完整计入可持续现金利润。最大前提是这些资金资产能按owner_earnback的折扣口径剥离或分配，同时白电主业在低毛利竞争中仍能维持约2.50亿元折前、1.625亿元折后可分配现金利润。按市值/折后现金利润30.80年看，它不是利润回本型便宜，更接近净现金/清算观察。

资产和净资产

2025年末，公司总资产223.03亿元，总负债158.12亿元，所有者权益64.91亿元；归母权益60.84亿元，少数股东权益4.08亿元，占权益6.28%。

资金类资产按事实包可识别为126.28亿元：货币资金101.87亿元，其中43.07亿元存放财务公司；一年内到期定存/大额存单6.56亿元，其他流动资产中的定存/大额存单1.24亿元，长期债权投资中的定存/大额存单16.61亿元。投资类资产中，其他非流动金融资产6.62亿元，主要是财务公司股权、基金和银行股权等，投资性房地产0.63亿元。经营资产事实包未完成全量归类，只能确认重要项：应收账款20.15亿元，是客户赊销和账期形成的欠款；存货20.80亿元，是家电库存和生产备货；固定资产22.76亿元，是工厂、产线和设备。

负债端主要是经营结算负债：应付票据70.05亿元、应付账款49.34亿元、合同负债8.72亿元，合计128.11亿元，反映对供应商票据/货款和客户预收款的占用。有息债务9.21亿元，包括短期借款8.10亿元、长期借款1.11亿元和一年内到期长期借款本息。另有租赁负债及一年内到期租赁负债1.44亿元，属于经营场地等付款义务。

可剥离现金直接复用owner_earnback：折后可剥离资金/投资资产92.83亿元，扣除有息债务9.21亿元、必要经营现金12.00亿元、税费汇兑分红和剥离摩擦准备3.00亿元后，折后可剥离净现金68.62亿元。普通货币资金、定存和大额存单可以按折扣扣；受限保证金和冻结资金不能扣；财务公司存款可以扣但折扣低，因为关联资金集中和实际可动用路径不如普通银行存款清楚。

业务和毛利

公司收入来自白色家电制造：冰箱柜、空调、洗衣机、厨卫小家电和生物医疗低温存储设备。2025年营业收入304.08亿元，其中家用电器制造收入301.33亿元，占99.09%；分销收入同样占99.09%，说明公司主要通过渠道和经销体系卖货。

分产品看，空调收入173.81亿元，占57.16%，同比增长12.81%；冰箱柜收入89.46亿元，占29.42%，同比下降6.42%；洗衣机收入22.07亿元，占7.26%，同比增长26.33%；厨卫及小家电14.44亿元。营业成本272.15亿元，主要是原材料、制造和采购成本，年报披露家电制造原材料成本247.01亿元，占营业成本91.32%。

整体毛利31.93亿元，毛利率10.50%。分产品经济性差异很大：冰箱柜毛利率14.84%，空调毛利率6.93%，洗衣机按收入22.07亿元、成本18.53亿元计算约16.00%。所以2025年空调拉动收入增长，但它是低毛利品类，收入结构向空调倾斜会稀释整体利润率。

从毛利到归母净利润

304.08亿元收入扣掉272.15亿元成本后，留下31.93亿元毛利。继续扣税金及附加1.11亿元、销售费用16.09亿元、管理费用4.09亿元、研发费用7.28亿元；财务费用为-0.02亿元，即利息收入和贴现等项目抵消后形成小额收益。销售费用主要是销售人员/劳务5.98亿元、市场支持费4.44亿元、运输1.75亿元、仓储租赁1.42亿元，这就是渠道销售人员、促销支持、物流和仓储体系的现实支出。管理费用主要是管理人员薪酬2.58亿元和折旧摊销0.49亿元。研发费用主要是研发人员薪酬3.09亿元、折旧摊销2.55亿元、试制和技术开发0.94亿元。

非主营项目对利润有帮助但不能当主业重复外推。其他收益1.47亿元，其中政府补助、增值税加计抵减等较重要；投资收益0.57亿元，包含债权投资利息收入0.53亿元、其他非流动金融资产持有收益0.16亿元、交易性金融资产处置收益和衍生金融资产处置损益；公允价值变动收益1.11亿元，主要来自衍生金融负债公允价值变化。由于大量现金、定存、大额存单和金融资产已经在净现金口径中扣掉，它们对应的利息和投资收益不能再完整进入可持续可分配现金利润。

公司2025年营业利润5.51亿元，利润总额5.47亿元，所得税1.18亿元，净利润4.30亿元；少数股东损益0.19亿元后，归母净利润4.10亿元，扣非归母净利润3.37亿元。

利润和现金流

2025年净利润4.30亿元、归母净利润4.10亿元，经营现金流8.60亿元；扣除购建固定资产、无形资产和其他长期资产支付4.26亿元后，经营自由现金流4.34亿元。现金流高于利润，主要不是因为主业突然变得高现金回报，而是折旧摊销和营运资金释放在起作用。

现金流调节表显示，固定资产和使用权资产折旧等2.83亿元，无形资产摊销1.69亿元，长期待摊费用摊销0.20亿元，这些非现金费用把利润加回现金。存货减少释放13.42亿元，代表成品、原材料和在产品库存下降；经营性应收减少释放6.43亿元，代表客户欠款和相关经营应收回收；但经营性应付减少20.20亿元，代表公司向供应商、票据和其他经营债权人结算，反向占用现金。

因此2025年经营现金流质量是“可用但波动大”：公司确实产生了自由现金流，但库存、应收和应付的方向变化很大，不能把2024年36.45亿元自由现金流那种高点当作常态。owner_earnback把折前可分配现金利润压到2.50亿元，再按0.65折扣到1.625亿元，是为了避免把资金收益和营运资金释放双算。

行业位置和上下游

公司年报称2025年家电市场在政策调整和行业转型中深度盘整，空调价格战、补贴节奏和原材料成本都影响经营；这只是公司视角，外部来源基本能交叉验证。电器杂志转载中国家用电器协会信息咨询部文章显示，2025年中国家电零售市场规模8931亿元，同比下降4.3%；白电零售额4837亿元，同比下降4.8%，其中空调零售额2357亿元同比下降0.4%，冰箱1271亿元同比下降11.5%，洗衣机963亿元同比下降4.6%。这支持报告中的判断：长虹美菱冰箱柜收入下降6.42%符合行业压力，空调能增长但低毛利，靠规模拉收入并不自动改善利润。

商务部通过新华社披露，2025年家电以旧换新超过1.29亿件，家电零售额突破万亿元且一级能效/水效产品占比超过90%。这解释了为什么公司仍强调绿色、智能、高端产品，并能在洗衣机、空调中取得收入增长；但同一行业资料也提示上半年补贴拉动后，三季度起增速回落，政策节奏变化会影响终端需求和渠道库存。

出口端，中国机电产品进出口商会2026年2月11日文章显示，2025年家电出口规模1294亿美元，同比仅增长0.6%，对美出口占家电整体出口比重从2020年的24%降至2025年的15%，新兴市场份额提升但增速放缓。长虹美菱2025年国外收入113.41亿元，占37.30%，海外业务是重要支撑，但它面对的是贸易保护、区域需求切换和本地化制造竞争，不应按单年10.80%的国外收入增速线性外推。

上游方面，公司家电制造原材料成本247.01亿元，占营业成本91.32%，主要原材料包括钢材、铜、铝、塑料和化工材料。证券时报2025年12月23日报道提到，中国家用电器协会提示理性看待“铝代铜”，争议背后是铜价上涨推动空调等产品制造成本攀升。对长虹美菱来说，这直接落在低毛利空调业务上：空调收入占57.16%，毛利率仅6.93%，原材料和汇率变化很容易吞掉利润。

投资和资本配置

2025年资本开支4.26亿元，主要投向固定资产、无形资产和其他长期资产，也就是生产线、设备、模具、信息化和研发能力。年报还披露若干后续项目：中山长虹以自筹资金约2.96亿元建设单班年产400万套空调项目，智慧家电约5.2亿元建设单班年产100万台洗衣机项目，合肥中大容积冰箱扩能项目总投资8.77亿元。这些项目都围绕主业，但在行业零售额承压、价格竞争加剧时，新增产能的利用率和回报率是关键。

资产配置的另一面是金融资产和资金资产：货币资金、定存和大额存单合计很大，其他非流动金融资产6.62亿元，投资性房地产0.63亿元。它们提高了账面安全垫，也贡献利息收入和投资收益；但估值回本分析已经把这些本金作为可剥离资产扣掉，所以不能再把由这些本金产生的收益完整作为经营业务的现金利润。

回本率和估值含义

复用owner_earnback公式：经营业务购买价 = 市值50.05亿元 - 折后可剥离净现金68.62亿元 = -18.57亿元。折后可持续可分配现金利润为1.625亿元。控股回本年数 = -18.57亿元 / 1.625亿元 = -11.43年；控股回本率 = 1.625亿元 / -18.57亿元 = -8.75%。负数不是收益承诺，只表示在本口径下折后净现金已超过市值。

市场整体口径仍要看市值/折后现金利润：50.05亿元 / 1.625亿元 = 30.80年，现金利润收益率为3.25%。这说明长虹美菱的吸引力更依赖净现金资产真实性和可剥离性，而不是主业利润足够厚。最敏感的前提有三项：财务公司存款和定存能按折扣实现；低毛利空调不继续拖累利润；2025年经营自由现金流不是由一次性营运资金释放撑起来的高估值分母。

风险判断

关联财务公司存款和净现金折扣风险：高。 行业背景是家电制造企业需要大量经营结算现金、票据保证金和集团资金管理，现金不一定都等同于普通可分配现金。公司2025年末货币资金101.87亿元，其中存放财务公司43.07亿元，受限货币资金4.16亿元。owner_earnback已把财务公司存款按0.55折扣、剔除受限资金，并扣必要经营现金和摩擦准备15.00亿元。主观判断：发生概率中、影响高，这是最能推翻净现金覆盖的风险；公开资料能确认金额，但不能确认逐笔调拨和剥离路径。

低毛利空调占比提升和价格竞争风险：高。 行业背景是2025年国内家电零售规模下降，政策刺激边际减弱，空调行业价格竞争强。公司空调收入173.81亿元，占收入57.16%，同比增长12.81%，但毛利率只有6.93%；冰箱柜毛利率14.84%且收入下降6.42%。公司归母净利润从2024年的6.99亿元降至2025年的4.10亿元。主观判断：发生概率高、影响中到高，收入增长如果继续来自低毛利空调，折后现金利润1.625亿元仍需打折看。

原材料和汇率波动风险：中。 上游背景是白电依赖铜、铝、钢、塑料和化工材料，外部报道也显示铜价上涨推动空调等产品制造成本攀升。公司家电制造原材料成本247.01亿元，占营业成本91.32%；财务费用中汇兑损失0.97亿元，远高于上年0.01亿元。主观判断：发生概率中、影响中，公司可以通过套保、产品结构、供应链效率和提价缓冲，但在10.50%整体毛利率、6.93%空调毛利率下，缓冲空间不厚。

客户集中和关联交易风险：中。 行业背景是家电销售依赖大渠道和经销体系，规模客户能带来出货，也会带来返利、账期和真实终端去化的不透明。公司前五名客户销售额176.42亿元，占年度销售总额58.02%，其中关联方销售额占25.92%；应收账款和合同资产前五名余额9.06亿元，占38.89%。主观判断：发生概率中、影响中，年报能确认集中度，但不能公开确认每个客户最终库存和商业条款，它会体现在利润率、应收和现金流波动上。

扩产项目低回报或减值风险：中。 行业背景是终端零售额承压和出口增速放缓时，新增产能必须靠产品升级、海外订单和渠道效率消化。公司2025年资本开支4.26亿元，并披露空调、洗衣机和中大容积冰箱相关投资项目。主观判断：发生概率中、影响中；项目围绕主业，不是明显跑偏，但若行业需求不足或价格战延续，新增折旧和产能利用率会压低利润。

已尝试但仍不可确认：财务公司存款、票据池保证金和应收款项融资质押的逐笔匹配。 已查年报货币资金附注、受限资产附注、关联交易章节和owner_earnback专题，公开资料只给合并金额和部分受限类别，没有逐笔账户、票据池合同和资金调拨限制。对结论的影响是：净现金覆盖仍可作为观察点，但必须使用折扣后口径，不能把账面资金全额视为可分红现金。
