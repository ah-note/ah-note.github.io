艾力斯（688578.SH）2025年度经营质量与控股回本研究

结论先行

艾力斯是一家财报模型清晰的普通经营型创新药公司，不属于银行、地产、收费权或投资控股等特殊模型。2025年公司几乎靠一个核心品种——第三代EGFR-TKI伏美替尼——赚钱：营业收入51.87亿元，伏美替尼收入51.20亿元；归母净利润21.89亿元，经营现金流23.23亿元，扣除1.86亿元购建长期资产支出后的经营自由现金流为21.37亿元。利润的现金转换良好，但产品集中度极高。

按2026年7月31日507.15亿元市值计算，结构性存款、定期存款和大额存单等可剥离资金合计57.03亿元。本报告对其打95折并扣除0.04亿元租赁融资负债，得到折后可剥离净现金54.14亿元；现金及现金等价物因未超过必要经营现金而不扣市值，ArriVent股权也不计入。市值减去折后净现金后，经营业务购买价约453.01亿元。

2025年归母净利21.89亿元、经营自由现金流21.37亿元。本报告进一步扣除政府补助、与可剥离资金对应的收益，并为单品和研发波动留余量，将折后可持续可分配现金利润定为19.00亿元。因此经营业务回本约23.84年，市值/现金利润约26.69倍。这个结果说明当前价格对伏美替尼持续商业化和管线兑现已有较高要求；它不是收益承诺，也不是买卖建议。

公司怎么赚钱

公司以创新药研发、生产和商业化为主。2025年抗肿瘤药品收入51.60亿元、毛利率97.28%，其中伏美替尼收入51.20亿元；戈来雷塞于2025年5月上市，贡献0.40亿元。技术授权及服务收入仅0.27亿元，且毛利率9.48%。因此，当期利润本质上来自伏美替尼在国内经销渠道的销售放量，而不是海外授权。

伏美替尼是中国原研第三代EGFR-TKI，2025年已覆盖EGFR敏感突变一线和T790M二线治疗；2026年2月又获批EGFR 20外显子插入突变二线适应症。公司的增长逻辑是扩大适应症、医保和临床覆盖，并借营销团队做医学推广。该模式库存占用低、药品毛利高，却需要持续的研发和商业推广支出。

经营数据说明什么

2025年收入51.87亿元，同比增长45.80%；营业成本仅1.65亿元，综合毛利50.23亿元，毛利率96.83%。归母净利润21.89亿元，同比增长53.10%，净利率42.20%。从50.23亿元毛利到净利润，最大扣项是销售费用20.76亿元，其次是费用化研发4.13亿元、管理费用1.67亿元及税费。销售费用同比增长46.91%，占收入40.02%，说明产品放量仍高度依赖营销组织和医学推广。

全年研发投入5.40亿元，占收入10.40%；其中利润表研发费用4.13亿元，另有部分形成开发支出。收入增速高于研发投入增速令比例下降，但不能据此认定未来研发需求降低。创新药的适应症扩展和后续管线仍需要多年投入。

经营现金流23.23亿元，高于归母净利润；扣除1.86亿元长期资产现金支出后，自由现金流21.37亿元，约为归母净利的97.6%。销售回款没有显著拖累当期利润兑现。不过，其他收益1.86亿元，结构性存款投资收益及公允价值收益合计0.54亿元，另有存款利息；这些不能无条件外推为药品经营利润。

资产负债对应的真实东西

2025年末总资产79.05亿元、总负债8.21亿元、归母权益70.83亿元，无少数股东权益。资金资产的主体不是活期现金，而是25.11亿元结构性存款，以及31.92亿元非现金等价物定期存款、大额存单和应收利息。这些资产与经营资产可以区分，但仍需考虑到期、利率、税费和研发资金安排，因此按95%计入可剥离价值。

经营性流动资产约5.84亿元，主要包括应收账款3.76亿元、预付款1.15亿元、存货0.72亿元等，代表销售回款、生产备货及研发经营预付，不能当作可拿走的现金。生产和研发相关资产约8.68亿元，包括固定资产5.12亿元、无形资产1.75亿元和开发支出1.74亿元等；无形资产增长主要与戈来雷塞获批适应症转入有关。

公司还持有1.80亿元ArriVent BioPharma股权，其价值随市场波动且带有战略合作属性，本次未从市值中扣除。负债主要是应付账款、员工奖金、税费及其他应付款；合同负债只有0.04亿元。有息融资几乎不存在，仅有0.04亿元租赁负债，因此账面没有明显财务杠杆压力。

分红和控股回本

2025年度中期已派现金1.80亿元，年末董事会预案2.70亿元，全年合计4.50亿元，占归母净利润20.56%；年末预案尚需股东会审议。按507.15亿元市值计算，近端预测分红率约0.89%。公司有能力分红，但当前大部分利润仍留存用于研发、经营和资金积累，分红率不能用净利润率简单替代。

控股回本计算如下：

折后可剥离净现金
= (25.1101亿结构性存款 + 31.9160亿定期/大额存单及应收利息) × 95%
- 0.0389亿租赁融资负债
= 54.1359亿元

经营业务购买价 = 507.15亿市值 - 54.1359亿 = 453.0141亿元
经营业务回本年 = 453.0141亿 / 19.00亿 = 23.84年
市值/现金利润 = 507.15亿 / 19.00亿 = 26.69倍

19亿元现金利润低于当年净利润和自由现金流，是对政府补助、资金收益、核心产品集中及研发波动的统一保守折减。若伏美替尼收入和费用结构稳定，口径有现金基础；若竞争或医保价格使产品利润下降，回本年会迅速拉长。

哪些事实会推翻判断

最关键的是单品集中：伏美替尼占公司收入约98.7%，任何竞争格局、医保价格、临床替代或安全性变化都会直接影响绝大部分现金利润。其次，销售费用占收入40.02%，若增长放缓而推广费用不能同步下降，利润弹性会反转。研发项目失败、审批延迟或资本化研发资产减值，也会增加未来现金消耗。

现金扣除同样有条件。本报告没有把4.46亿元现金等价物认作超额现金，也没有计入ArriVent股权，已相对审慎；但若结构性存款或定期存款存在未披露的用途约束，或未来全球临床和商业化需要更多资金，54.14亿元仍可能高估可分配性。反过来，若新适应症和戈来雷塞形成可验证的独立现金流，19亿元可持续利润可能偏低。

来源与口径限制

核心财务和业务数据来自公司2025年年度报告（巨潮资讯官方披露，PDF第2、11-12、40-41、130-137页及相关附注）；资金资产明细复用了已按年报第159、160、172、186、191、192、208页核对的年度ROIC结果包。市值和PE TTM来自输入中的腾讯行情快照（2026-07-31 11:43:39）。年末分红尚待股东会审议，存款利息未由年报按资金种类完整拆分，可持续现金利润因此包含分析判断。

本报告区分了审计事实、计算结果和主观折扣，不提供买卖建议或目标价。
