格力电器进榜不是因为账面现金能完全覆盖市值，而是因为在扣掉折后可剥离净现金后，剩余经营业务购买价约1994.18亿元，对应折后可持续可分配现金利润204.00亿元，控股回本约9.78年。便宜主要来自利润，而不是纯现金折价：折后净现金只覆盖市值约12.25%。最大前提是消费电器主业仍能维持两百亿元级别的可分配现金利润，同时已作为可剥离净现金扣掉的定存、理财、债权和交易性金融资产，其利息和投资收益不能再完整计入利润分母。

资产和净资产

2025年末，格力总资产3913.72亿元，总负债2415.81亿元，所有者权益1497.91亿元；其中归母权益1459.29亿元，少数股东权益38.62亿元，少数股东权益占所有者权益约2.58%。这是一家资产负债表很重的制造和渠道公司，但重的部分不全是厂房设备，更多是现金、定存、理财和渠道经营负债。

资金类资产按事实包已抽取重要科目合计2620.03亿元：货币资金1105.53亿元，交易性金融资产313.36亿元，一年内到期的非流动资产333.39亿元，其他流动资产中的货币性投资产品130.03亿元，其他债权投资240.62亿元，其他非流动资产中的货币性投资产品426.10亿元，另有买入返售金融资产48.01亿元、发放贷款和垫款22.98亿元。这里面既有银行存款和定期存款，也有财务公司相关资金资产，不能全部视为股东可拿走的钱。

经营资产已抽取864.01亿元，主要是客户欠款和票据回款资产、生产备货、工厂设备：应收账款159.87亿元，应收款项融资64.96亿元，存货281.83亿元，固定资产343.96亿元，在建工程13.38亿元。投资类资产70.16亿元，主要是长期股权投资42.35亿元、其他权益工具投资24.20亿元和投资性房地产3.61亿元。其他资产按总资产倒算约359.52亿元，其中已具名的递延所得税资产167.12亿元、商誉13.24亿元等需要保留为非经营现金资产或特殊资产。

负债侧，有息融资854.13亿元，包括短期借款679.57亿元、一年内到期非流动负债136.68亿元、长期借款31.35亿元、租赁负债6.53亿元。经营负债已抽取1214.26亿元，主要是供应商票据155.44亿元、应付账款421.04亿元、合同负债152.07亿元和销售返利485.71亿元。合同负债主要是经销商预收货款，销售返利是渠道销售政策形成的未来结算义务；这两项说明格力不是简单把货卖给终端消费者，而是通过经销和渠道体系周转。

可剥离现金直接复用 owner_earnback 的折后结果：折后可剥离净现金278.31亿元。可扣的是经折价后的普通可动用银行存款、定期存款、未质押货币性投资产品、债权投资和交易性金融资产；不能扣的是受限存款、质押资产、财务公司相关存放央行/同业、买入返售、贷款资产，以及为制造、渠道返利和售后保留的必要经营现金。这个处理比账面资金类资产保守得多，也更接近控股后实际能调走的钱。

业务和毛利

格力2025年营业收入1704.47亿元，同比下降9.89%。消费电器收入1330.55亿元，占收入78.06%，同比下降10.44%，毛利率35.28%；工业制品及绿色能源收入173.81亿元，占收入10.20%，同比增长0.78%，毛利率15.53%；智能装备收入6.81亿元，规模还小；其他主营和其他业务合计193.30亿元。

营业成本1196.41亿元，基本对应空调和其他家电的原材料、零部件、人工、制造费用、安装交付相关成本。收入扣成本后的毛利508.06亿元，综合毛利率29.81%。消费电器贡献的毛利约469.43亿元，是绝对利润池；工业制品及绿色能源毛利约27.00亿元，虽然是第二业务，但经济性明显低于消费电器。

分部数字说明，格力的核心经济性仍取决于空调和消费电器品牌、渠道、规模制造效率。2025年收入下降但消费电器毛利率同比小升0.37个百分点，说明当年报表中还没看到主业毛利崩塌；真正需要盯的是未来价格竞争是否继续把收入下滑传导为毛利率下滑。

从毛利到归母净利润

1704.47亿元收入扣1196.41亿元成本后，留下508.06亿元毛利。再扣税金及附加19.12亿元、销售费用84.11亿元、管理费用51.80亿元、研发费用64.63亿元。销售费用主要是安装费、仓储装卸费、宣传推广费和职工薪酬，代表把空调和家电送到渠道、安装到用户家里以及维护品牌曝光的成本；管理费用主要是职工薪酬、物耗、折旧摊销；研发费用主要是研发人员和直接投入。

财务费用为-40.86亿元，反而增加利润，核心是利息收入58.85亿元，高于利息费用19.65亿元。这里必须单独看：这些利息收入来自资金收益，而回本模型已经把大量定存、理财、债权投资和交易性金融资产本金作为可剥离资金折扣扣除，所以不能把这些本金对应收益完整当作可持续经营现金利润。owner_earnback 因此把折前可分配现金利润压到240.00亿元，再打0.85折。

非主营和辅助项目也不小：其他收益13.39亿元，其中政府补助9.81亿元；投资收益4.02亿元；公允价值变动收益1.64亿元；信用减值转回5.12亿元；资产减值损失13.57亿元。最后营业利润346.81亿元，所得税57.82亿元，净利润288.63亿元；少数股东损益为-1.40亿元，归母净利润290.03亿元。

利润和现金流

2025年净利润288.63亿元，归母净利润290.03亿元，经营现金流463.83亿元，资本开支17.17亿元，经营自由现金流446.66亿元。表面看现金流明显强于利润，但不能简单把463.83亿元当作常态现金利润。

现金流高于利润的主要来源是非现金费用和营运资金变化。折旧、投资性房地产折旧及使用权资产摊销46.07亿元，无形资产摊销4.48亿元，资产及信用减值准备8.45亿元，这些会减少会计利润但不当期流出现金。经营性应收减少19.84亿元，说明客户欠款和票据等经营应收回收了一部分现金；但存货增加2.74亿元占用现金，经营性应付减少32.56亿元，说明公司对供应商和渠道等经营负债净支付了部分现金。

更关键的是现金流补充资料中的“其他”170.92亿元。owner_earnback 已核查其中包含票据保证金等受限资金净减少156.67亿元，这属于以前被限制的资金释放，不是每年卖空调都能自然产生的现金利润。因此回本口径没有使用2025年经营自由现金流446.66亿元，而是使用折后可持续可分配现金利润204.00亿元。

行业位置和上下游

公司年报说消费领域覆盖家用空调、暖通设备、冰箱、洗衣机、热水器、厨房电器、环境电器等，同时发展工业制品、绿色能源和智能装备。这个自我描述只能说明业务范围，判断行业环境还需要外部核查。

外部政策端，国家发展改革委转载的商务部等4部门2025年家电以旧换新通知明确把空调纳入补贴品类，2级及以上能效或水效产品补贴15%，1级及以上额外补贴5%，空调每位消费者最高可补贴3件、每件不超过2000元。这个来源支持的判断是：2025年格力内销主营收入下降10.67%，不是发生在没有政策支持的环境里，而是在政策托底下仍然下降，所以公司自身渠道、产品结构、价格和份额压力需要重点看。

行业监测端，新浪科技转载家电网文章引用奥维云网数据称，2025冷年中国空调生产2亿台、同比增长11.1%，总销量1.96亿台、同比增长11.5%，其中内销出货1.02亿台、同比增长8.7%，出口9396万台、同比增长14.7%；同时文章指出国补、价格激战和高温共同拉动零售，下半场价格竞争明显。这个来源支持的判断是：行业量端并不差，但量增不等于格力收入一定增长；如果公司没有在价格竞争和渠道迁移中守住份额，收入会先掉，后续才可能压毛利。

国家统计局《中华人民共和国2025年国民经济和社会发展统计公报》披露，2025年房间空气调节器产量26697.5万台，同比增长0.7%。这个自然年度口径比冷年监测口径更平，说明行业判断要看统计周期：2025冷年的补库、高温和政策节奏较强，但自然年度制造产量只是小幅增长。对格力数字的含义是，库存、应收和渠道返利不能只按单一高景气口径解释。

上游主要是压缩机、电机、铜铝钢塑、电子控制器和制冷剂等材料及零部件，最终进入1196.41亿元营业成本和281.83亿元存货。下游主要是经销商、线上平台、工程和终端家庭用户，体现在152.07亿元合同负债和485.71亿元销售返利。渠道返利这么大，说明格力的渠道不是一次性现金零售生意，渠道政策变化会直接影响收入确认、销售费用、返利负债和现金流节奏。

投资和资本配置

2025年资本开支17.17亿元，低于2024年的33.00亿元，也远低于当年经营现金流和归母净利润。期末固定资产343.96亿元、在建工程13.38亿元，说明既有生产体系仍是核心资产，但当年没有出现大规模新增产能投入。

资金更多沉淀在金融和类现金资产中。货币资金1105.53亿元，其中现金及现金等价物275.66亿元，定期存款及应计利息724.09亿元，受限存款105.78亿元；交易性金融资产313.36亿元，债务工具为主；一年内到期非流动资产333.39亿元，其他流动资产中的货币性投资产品130.03亿元，其他债权投资240.62亿元，其他非流动资产中的货币性投资产品426.10亿元。这些资金一方面提供利息和投资收益，另一方面也带来期限、质押、主体和财务公司口径的不透明。

受限资产合计479.63亿元，包括受限货币资金105.78亿元、质押的一年内到期非流动资产104.70亿元、质押其他债权投资79.00亿元、质押其他非流动资产133.00亿元，以及部分固定资产、无形资产等。长期股权投资42.35亿元、其他权益工具投资24.20亿元、投资性房地产3.61亿元规模不算决定性，但投资收益和公允价值变动在利润桥中需要单独看，不能混同为空调主业利润。

回本率和估值含义

本节完全复述 owner_earnback 主口径。市值2272.49亿元，折后可剥离净现金278.31亿元，因此经营业务购买价为：

2272.49亿元 - 278.31亿元 = 1994.18亿元

折后可持续可分配现金利润204.00亿元，因此控股回本年数为：

1994.18亿元 / 204.00亿元 = 9.78年

控股回本率为：

204.00亿元 / 1994.18亿元 = 10.23%

市值/折后现金利润为：

2272.49亿元 / 204.00亿元 = 11.14年

现金利润收益率为：

204.00亿元 / 2272.49亿元 = 8.98%

这个回本数最依赖三件事。第一，折后净现金278.31亿元要真实可剥离，受限、质押、财务公司资金和必要经营现金不能混进去。第二，204.00亿元现金利润已经扣掉大额资金收益双算风险，如果未来主业利润下降，回本年数会迅速变长。第三，消费电器的收入下滑不能演变成毛利率和渠道现金流一起恶化。

风险判断

消费电器收入和份额继续下滑：高。 行业背景是2025年空调有国补政策托底，冷年行业出货和零售量增长，但价格竞争和渠道变化也明显。历史变化上，格力2025年营业收入下降9.89%，消费电器收入下降10.44%，内销主营下降10.67%，外销主营下降2.93%。公司数字显示消费电器仍贡献1330.55亿元收入和约469.43亿元毛利，是利润中枢。主观判断为概率中、影响高：2025年毛利率还稳，但行业量增下公司收入下降，是最可能推翻204.00亿元现金利润前提的风险。

大额资金可剥离性不足：中。 行业背景是制造企业保留一定现金很正常，但格力合并口径含财务公司相关金融资产，不能把所有资金资产当作普通上市公司超额现金。历史变化和公司数字显示，期末资金类资产很大，但受限资产479.63亿元，融资负债854.13亿元。owner_earnback 已把折后可剥离净现金压到278.31亿元。主观判断为概率中、影响中：当前口径已经保守，真正不能公开确认的是逐笔定存、理财和债权投资的主体、期限、提前变现条款。

资金收益与利润双算：中。 2025年财务费用为-40.86亿元，其中利息收入58.85亿元，另有投资收益4.02亿元、公允价值变动收益1.64亿元。若把对应本金扣作净现金，又把收益完整当作经营利润，就会高估回本率。本报告复用 owner_earnback 的处理：折前可分配现金利润取240.00亿元，再打0.85折到204.00亿元。主观判断为概率低、影响中：本报告已处理双算，但204.00亿元仍依赖主业利润稳定。

库存跌价和价格战压力：中。 行业背景是2025冷年价格竞争明显，低价段份额提升。公司数字显示，期末存货账面余额314.50亿元，跌价准备32.67亿元，账面价值281.83亿元，其中产成品账面价值158.80亿元。历史变化上，2025年消费电器毛利率35.28%，同比小升0.37个百分点，说明当年没有明显毛利崩塌。主观判断为概率中、影响中：如果价格战延续，库存跌价和毛利率下行会直接压缩现金利润。

应收账款和特殊客户回款：中。 公司2025年应收账款账面余额190.66亿元，坏账准备30.79亿元，账面价值159.87亿元；1年以上应收账款主要为废弃电器电子产品处理专项资金以及新能源汽车货款，60家单位单项100%计提坏账11.90亿元。历史变化上，经营性应收减少19.84亿元释放现金，说明2025年没有出现应收大幅吞现金，但账龄结构仍需要保守。主观判断为概率中、影响低到中：目前不足以单独推翻回本结论，但会影响利润现金化质量。

已尝试但仍不可确认。 逐笔定期存款、货币性投资产品和债权投资的主体、期限、收益率、提前变现条款及与质押债务的对应关系，公开年报只披露汇总和部分受限金额，已查年报附注五、1、11、12、15、28、29、71及 owner_earnback，仍需要公司IR或管理层确认。2026年及以后补贴退坡、渠道库存和价格战对格力销量/毛利的实际影响属于未来事件，已查2025年政策和行业资料，但不能用公开资料确认公司未来执行结果；它对结论的影响是，如果204.00亿元折后现金利润不可持续，9.78年回本会拉长。
