结论

招商局港口不是一组可以只按吞吐量乘单价理解的全资码头。它有两层经济结构：第一层是纳入合并报表的境内外码头、保税物流和投资物业，2025年形成133.54亿港元收入和52.76亿港元EBIT；第二层是上海港、Terminal Link等权益法联营及合营港口，2025年贡献49.70亿港元利润，但没有进入合并收入和并表经营现金流。研究把两层分开计值：前者按维持后经营收益估经营资产，后者作为非经营资产进入价值桥，避免把股息和投资价值重复计算。

这门生意的强处是稀缺岸线、腹地货源、航线密度、长期特许权和全球网络共同形成的进入壁垒；弱处是大量价值锁在无单方控制权的权益法投资中，账面利润不等于上市公司可立即分配的现金。2025年并表海外码头是最重要的利润引擎，收入约占51%，本研究估算其EBIT约占67%；大中华区并表码头收入约占42%，但部分成熟港区增长较慢。公司整体集装箱吞吐量增长3.8%至1.513亿TEU，海外项目增长5.7%，但辽宁港、台湾KMCT和吉布提PDSA均下滑，组合内部差异很大。《Annual Report 2025》，管理层讨论与分析，第19—22页

在没有可靠项目级成长现金流的情况下，本报告采用固定标尺而不是成长估值。稳定期收入取130亿港元、EBIT 51亿港元、维持后经营收益53.5亿港元；八倍经营价值为428亿港元。加上104.95亿港元多余现金和825.16亿港元非经营资产，扣除347.75亿港元融资负债和166.35亿港元少数股东经济价值，普通股基准价值约844亿港元，即每股20.1港元。该数值对权益法投资的折扣最敏感，并非精确公允价值，也不是买卖建议。任务输入没有提供当前股价、观察时间和来源，因此不计算市场折溢价。

客户为什么付款，订单怎样形成

直接客户主要是船公司、货主及其物流服务商。码头把船舶靠泊、装卸、堆存、集疏运和报关辅助服务组织成连续履约过程；2025年并表收入中，124.47亿港元来自码头装卸及辅助服务，7.05亿港元来自仓储，2.02亿港元来自投资物业租金。装卸和仓储收入按合同价格扣除折扣确认，说明决定收入的不是海运运价本身，而是靠泊航线、箱量、服务组合、合同费率和折扣。《Annual Report 2025》，附注4，第130—131页

订单形成先取决于港口是否位于足够大的腹地或中转网络，再取决于泊位水深、效率、班轮网络和持续服务能力。船公司改挂港成本高，但并非不能改；因此长期服务合同、稳定效率和航线密度比一次性装卸报价更重要。Kumport在签下船公司长期服务合同后，2025年箱量增长22.8%；LCT在扩充能力并能常态化服务24,000 TEU船舶后，箱量增长17.9%。相反，香港码头合计下滑8.1%，KMCT下滑24.9%，说明地理位置和既有资产并不能自动保证货量。《Annual Report 2025》，第17、20—22页

客户集中度值得留意。2025年单一客户贡献24.11亿港元，占合并收入约18.1%，高于2024年的20.28亿港元。年报没有披露客户名称或合同期限，因此不能把该收入视作永久锁定；如果该客户调配航线，短期内固定港口资产很难同步收缩。《Annual Report 2025》，附注5，第132页

供给、交付与难复制环节

港口供给不是普通设备采购。泊位、航道、堆场、岸桥、疏港连接和政府特许权必须在同一地点形成完整系统，审批和建设期长；一旦建成，新增一个集装箱的边际履约成本较低，但空置资产成本很高。这解释了吞吐量上升时海外码头利润弹性较大，也解释了货源迁移时弱港区很难靠削减成本完全抵消。

集团的差异化能力来自三处。第一是全球节点组合，能在中国、南亚、非洲、欧洲、土耳其和拉美连接班轮客户。第二是本土港区与腹地货源，例如西深圳港区2025年箱量超过1,500万TEU。第三是把运营方法和系统复制到海外；CMCore码头操作系统已在巴西、意大利和土耳其项目落地，西深圳推进SMP精益成本分析，并以集中采购和工程管理降低成本。《Annual Report 2025》，第16—18页

保税物流规模小，但对港口客户有黏合作用。深圳CMBL和CMITQ仓库平均利用率分别达到99%和97%，吉布提自有保税仓为89%；高利用率支持现有资产收益，却也意味着不扩建时新增量空间有限。《Annual Report 2025》，第22页

定价、成本与利润形成

2023—2025年合并收入从114.82亿增至133.54亿港元，毛利率从44.9%升至48.7%。2025年收入增长12.8%，公司解释主要来自业务量增长；同期集装箱吞吐量增长3.8%，两者差距还包含并表范围、业务组合、费率和汇率影响，不能把收入增速全部当作同店提价。《Annual Report 2025》，第23页及合并损益表第85页

直接成本主要是人员、设备运行与维修、能源、港口特许费和堆场履约成本。2025年员工成本23.15亿港元，占公司所称总经营费用28.3%；折旧摊销22.85亿港元，接近销售成本的三分之一，反映这是一门资本和特许权密集的业务。《Annual Report 2025》，第26页及附注6第137页

期间经营费用必须正常化。2024年其他收入及其他收益净额10.45亿港元，使表观净期间费用降至4.12亿港元；2025年该净收益仅1.05亿港元，净期间费用回到12.29亿港元。稳定期采用12.5亿港元，不把2024年的高额其他收益当作持续降本。权益法利润波动更大：联营和合营利润由2024年的65.13亿降至2025年的49.70亿，正是归母利润下降的主因之一。《2024 Annual Report》，合并损益表第83页；《Annual Report 2025》，合并损益表第85页

现金形成与维持投入

2025年合并经营现金流是94.72亿港元，其中包含权益法投资股息27.30亿港元，也包含与该股息有关的1.91亿港元预提税。为与单独列值的联营合营资产保持一致，剔除股息并加回对应预提税后，并表经营现金流为69.33亿港元。《Annual Report 2025》，合并现金流量表第91页

现金资本开支也不能只取“购买长期资产”8.73亿港元。采用经营租赁与特许权口径后，还需计入租赁、特许权和最低特许费本金4.66亿港元，并扣除资产处置回款0.08亿港元，得到13.31亿港元。2023和2024年同口径分别约13.96亿和12.87亿港元。《Annual Report 2025》，合并现金流量表第91—92页；《2024 Annual Report》，合并现金流量表第89—90页

本研究把2025年13.31亿港元现金资本开支拆为9.99亿维持、3.05亿既有业务扩张和0.27亿开拓性投入；稳定期维持投入取11亿港元。它低于22.85亿港元折旧摊销并不必然表示少投：码头土建和特许权寿命长，折旧还包含历史收购形成的资产摊销。但如果未来五年现金资本开支持续显著高于折旧而吞吐能力没有增长，或公司披露的安全、环保和设备更新预算明显高于11亿港元，这个维持投入估计必须上调。

2025年实际并表FCFF约56.02亿港元，其中2.93亿港元来自经营性营运资金释放，不应永久外推。稳定状态把营运资金增加设为零，维持后经营收益为53.5亿港元。

扩张投入与当前阶段

公司处在“成熟资产产生现金、海外节点继续扩张”的混合阶段。2025年海外箱量增长5.7%，HIPG和NPH受新业务或并表影响增长很快，LCT、Kumport、TCP和TICT也有两位数或接近两位数增长；但部分中国及亚洲港区下滑。集团还签署巴西Vast项目股权购买协议。《Annual Report 2025》，第17、19—22页

这些事实证明扩张在发生，却不足以支撑公司特定成长估值：年报没有把各项目剩余总投入、投产时间、利用率爬坡、增量价格和逐年FCFF完整连在一起。因此扩张项目和新业务选项在价值桥中均暂计零。若未来披露项目级投入、投产期、合同箱量和增量FCFF，并能证明回报高于资金成本，则应从零改为独立正值；反之，若扩张只维持现有吞吐，其支出应转入维持性资本开支。

资本占用与资产效率

2025年经营性营运资金为负16.79亿港元，主要因为经营应付和合同负债大于存货及经营应收。负营运资金降低资本占用，但不能把延迟付款当作竞争优势；应收政策仍给予客户平均90天信用期。《Annual Report 2025》，附注25第161页及附注34第174页

经营投入资本还包括码头固定资产、使用权资产、特许经营权、投资物业及12亿港元经营必需现金，并扣除租赁和长期经营负债；53.05亿港元商誉全部剔除。2025年投入资本约453.28亿港元，ROIC约9.6%，较2023年的7.2%改善。这个比率只衡量并表经营资产，不包含948.69亿港元联营合营投资，因此不能代表集团全部资本的回报，也不适合直接与全资码头运营商比较。

投资物业保留在经营资产中，因为其2.02亿港元租金和0.71亿港元直接费用已进入并表收入与EBIT；若再把59.47亿港元物业账面值作为非经营资产加回，就会重复计值。《Annual Report 2025》，附注4第130页及合并财务状况表第87页

股东资金可达性

年末现金及银行结余117.43亿港元，其中62.2%为人民币；公司本体现金42.11亿港元。集团另有276.28亿港元未提取双边授信，短期再融资压力可控，但这不等于所有子公司现金都可无摩擦上划。《Annual Report 2025》，第23页及公司财务状况表第205页

招商局集团直接及间接控制公司72.15%，公众持股27.85%。高度控股结构有利于集团内长期部署，也使少数公众股东依赖控股股东的分配政策。正面证据是2025年全年股息每股0.739港元、派息率48.1%；反面证据是大量价值仍锁在联营合营层级，2025年收到的27.30亿港元股息仅为相关账面值约2.9%。《Annual Report 2025》，第10页、第65—66页及现金流量表第91页

因此价值桥没有按948.69亿港元账面值全额加入权益法投资，而是按75%、即711.52亿港元计值。25%折扣不是会计减值结论，而是对缺乏单方控制、处置税费和现金分派时点的研究调整。若主要上市持股市值、非上市项目可比交易和持续分红证明账面价值可以高比例兑现，折扣应收窄；若股息下降、资本继续沉淀或项目减值，折扣应扩大。

稳定状态与普通股价值

稳定状态不是把2025年增长率外推，而是让销量、利润率、税、折旧和维持投入彼此一致：收入130亿港元，毛利率48.8%，净期间经营费用12.5亿港元，EBIT 51亿港元，经营现金税9亿港元，NOPAT 42亿港元，折旧摊销22.5亿港元，维持性资本开支11亿港元，正常营运资金增加为零。由此得到维持后经营收益53.5亿港元。

八倍标尺给并表经营资产428亿港元。价值桥中的多余现金为104.95亿港元，等于账面现金扣12亿经营必需现金和0.48亿非现金等价余额；非经营资产825.16亿港元，包括折价后的权益法投资711.52亿、其他金融资产106.42亿，以及从经营营运资金剔除的关联方、股息和税项应收。扣除347.75亿融资负债及以账面权益替代的166.35亿少数股东价值后，普通股基准价值约844亿港元、每股20.1港元。

少数股东价值是另一项低置信度输入。并表FCFF包含非全资子公司100%现金流，必须扣除不属于上市公司普通股股东的部分；由于缺少各子公司的独立债务、现金和项目估值，本报告暂以少数股东账面权益替代。若主要非全资海外码头的独立估值使该索偿偏离账面值20%以上，应重做价值桥。《Annual Report 2025》，合并财务状况表第88页

主要风险、反证与观察点

最重要的经营反证不是全球贸易停止增长，而是公司组合跑输所在市场。2025年中国大陆港口集装箱吞吐量增长6.8%，集团大中华区、香港及台湾组合增长3.2%；两者范围并不完全一致，但足以提示成熟资产、地区结构或份额压力。若西深圳以外核心港区连续两年低于当地市场，稳定收入和毛利率均应下调。《Annual Report 2025》，第15、19页

第二，增长集中在少数海外项目。Kumport、LCT、TICT和NPH增长强劲，但CICT下降3.0%、PDSA下降13.6%；地缘政治、特许权续期、汇率和当地监管会使单项目现金流偏离组合平均。第三，347.75亿港元借款中57%以港元计价，经营资产和现金流则分布在人民币、美元、欧元、巴西雷亚尔等多种货币，汇率既影响利润换算，也影响债务覆盖。《Annual Report 2025》，第24—25页

第四，权益法资产是估值最大变量。2025年相关利润同比下降23.7%，但收到股息基本持平；短期看现金韧性好于利润，长期仍须观察上海港、Terminal Link及其他项目的分红、资本开支和减值。第五，低于折旧的现金资本开支可能只是项目时点，也可能意味着未来补投。年度维持投入若持续超过11亿港元，每增加1亿港元，八倍标尺下经营价值约减少8亿港元。

口径与估计说明

金额默认以亿港元列示。EBIT采用分部披露的“扣除净融资成本、税项及联营合营利润前盈利”，不使用混入融资和权益法投资收益的利润总额。经营现金税采用香港、内地和海外实际支付所得税之和，不含联营合营股息预提税。历史FCFF同时以利润路径和剔除权益法股息后的现金流路径闭合。

业务表中的收入、EBIT和折旧摊销以附注5分部资料控制；销售成本、期间费用、经营现金税、资本开支分类、营运资金和投入资本为在公司合计约束下的单一基准点估计。大中华区包括附注5列示的珠三角、长三角、环渤海及境内其他并表码头；海外并表码头单列；保税物流单列；投资物业与总部职能合并为“物业租赁与总部平台”，以保留总部成本而不制造“其他”占位业务。

表内“非经营资产”是相对并表FCFF的估值分类，不表示联营合营港口不是公司的核心业务。相反，它们在经济上属于核心港口网络，只是会计上不进入合并收入和并表经营现金流，必须在价值桥单独处理。
