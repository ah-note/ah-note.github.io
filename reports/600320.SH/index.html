振华重工（600320.SH）2025年度经营质量与控股回本研究

报告期为2025年12月31日，市场估值采用输入提供的2026年7月31日腾讯行情快照：总市值225.51亿元，PE TTM 26.44倍。本文不构成买卖建议；“回本年”只是按统一口径对当前经营资产价格和保守现金利润的比值测算。

结论先行

振华重工是项目型重型装备制造商，而不是简单的标准品工厂。公司依靠大型港机设计制造、全球整机交付和系统集成赚钱，岸桥细分品类保持行业龙头；2025年收入增长5.24%，归母净利润增长37.17%，港机是主要收入和利润基础。与此同时，综合毛利率只有13.74%，大量资金沉淀在在产品、应收及合同资产中，利润还持续受到减值侵蚀。

普通经营公司模型仍可使用：2025年约77%的收入在某一时点确认，核心经济活动是设备制造和交付。但必须加上项目型制造约束。账面238.65亿元存货、30.70亿元合同资产、215.79亿元合同负债以及项目融资彼此关联；客户预付款要用于后续履约，不能当作可分配现金。

按控股口径，公司不存在可剥离净现金。现金及交易性金融资产合计49.74亿元，而短期借款、一年内到期非流动负债和长期借款合计210.46亿元。对可持续现金利润，本研究不把2025年62.49亿元经营现金流直接外推，而采用4.99亿元扣非归母净利润作为保守代理。由此经营业务购买价仍为225.51亿元，市值/现金利润及回本年约45.2倍/年。这个结果的主要不确定性是项目现金周期和维护性资本开支缺少逐项目拆分。

公司怎么赚钱

公司向港口运营商、海工和大型工程客户提供研发设计、采购制造、运输、安装、系统集成及运维服务。项目通常金额大、周期长：签约后收取部分预付款，采购钢材和部件并组织制造，形成大额在产品；达到交付或履约进度后确认收入，再进入结算、质保和回款阶段。因此，交付节奏不仅决定收入，也会显著改变存货、合同资产、合同负债和经营现金流。

2025年主营业务收入361.03亿元，其中港口机械227.76亿元，占约63%，毛利率15.25%；重型装备73.83亿元，毛利率7.59%；钢结构33.97亿元，毛利率6.42%；船舶运输及其他22.62亿元，毛利率35.00%；工程建设项目2.86亿元，毛利率为-31.12%。利润主要来自港机的规模、品牌、全球交付和一体化服务能力，高毛利的船运及其他业务规模较小，重型装备和钢结构则属于薄利项目。

公司的位置较清楚：岸桥细分品类连续多年保持行业龙头，产品进入全球111个国家和地区；上海、江苏生产基地拥有长岸线、重型制造设备和整机运输船队，这些资源构成大型产品交付门槛。反面是行业竞争、原材料及供应链波动、项目成本控制和海外交付都可能压缩本就不高的毛利。

2025年经营数据说明什么

营业收入362.60亿元，同比增长5.24%；营业成本312.78亿元，同比增长4.05%，因此毛利49.82亿元，综合毛利率13.74%，较上年略有改善。归母净利润7.32亿元，同比增长37.17%，净利率仅2.02%；扣非归母净利润4.99亿元，同比增长136.35%。收入与利润增长主要来自项目交付量增加。

从毛利到归母净利润之间，研发费用15.15亿元、管理费用8.38亿元、销售费用2.37亿元、财务费用3.30亿元；信用减值损失5.46亿元、资产减值损失3.87亿元，两项合计9.32亿元，约为当年归母净利润的1.27倍。这说明薄毛利之下，应收回款和项目估值变化对最终利润非常重要。

经营现金流62.49亿元，减去购建长期资产支付的10.50亿元，表观经营自由现金流为52.00亿元，远高于净利润。但现金流量表补充资料显示，经营性应付项目增加贡献24.83亿元，存货减少贡献6.69亿元，建造合同款减少/释放贡献7.20亿元，同时经营性应收增加消耗12.87亿元。现金改善有真实的回款和去库存成分，也高度依赖项目结算与供应商付款节奏，不能视为每年可重复分配的52亿元。

资产负债对应哪些真实东西

资产端最重要的不是现金，而是项目与产能：

  • 货币资金45.70亿元，其中存放财务公司11.30亿元；交易性金融资产4.03亿元，主要是上市股票。集团有息债务显著更高，故本研究不确认可剥离净现金。
  • 存货238.65亿元，其中在产品账面价值约200.02亿元，代表尚在制造和履约过程中的大型设备；应收账款84.86亿元，合同资产30.70亿元，后者主要是质保尾款及已完工未结算项目。三项合计354.21亿元，是经营资金占用核心。
  • 固定资产229.08亿元、在建工程14.43亿元、无形资产43.96亿元，对应生产基地、码头岸线、重型设备、船舶及土地等交付能力，不能从持续经营业务中轻易剥离。
  • 长期应收款12.63亿元、长期股权投资17.86亿元、其他非流动资产46.10亿元中包含PPP相关资产；部分资产已用于项目借款质押，变现受期限及融资安排限制。

负债端体现了客户、供应商和银行共同为项目周期提供资金：

  • 合同负债215.79亿元，其中预收产品款205.04亿元、已结算未完工款10.75亿元。这些款项带来现金，但对应未来制造和交付义务。
  • 应付账款127.33亿元、应付票据46.89亿元，主要对应材料采购、制造、基建和质保，是供应链融资而非无条件的剩余资金。
  • 短期借款36.87亿元、一年内到期非流动负债43.09亿元、长期借款130.50亿元，合计210.46亿元。长期借款中约30.54亿元以PPP项目相关资产质押，集团是明显净负债结构。

利润能否成为可分配现金

2025年归母净利润7.32亿元，扣除非经常性损益后为4.99亿元。折旧摊销约16.25亿元，而资本开支10.50亿元，单年看会计折旧已覆盖资本开支；但大型基地、船舶和设备的维护性资本开支没有独立披露，也不能据此认定差额都可分配。

本研究将可持续可分配现金利润定为4.99亿元：以扣非归母净利润为代理，不额外加入2025年的营运资金释放。这样处理牺牲了部分上行可能，但避免把客户预付款、存货去化或延后支付供应商形成的一次性现金高峰永久化。

2025年度现金分红包括已实施的半年度每股0.02元和年报提出的年度每股0.055元，合计3.9435亿元，占归母净利润53.88%。按225.51亿元市值计算，预测分红率约1.75%。年报披露时，年度分红预案仍待股东会审议，因此该收益率不是无条件确定的现金回报。

控股回本口径

计算如下：

折后可剥离净现金 = 0
经营业务购买价 = 225.51亿元 - 0 = 225.51亿元
折后可持续现金利润 = 4.989亿元
控股回本年 = 225.51 / 4.989 = 约45.2年
市值 / 现金利润 = 约45.2倍

净现金按零计并不表示现金没有价值，而是现金优先服务于高额有息债务、项目履约和日常周转，在控股后没有足够证据证明它能从业务中抽离。45.2年的结果也不是增长预测；若未来港机交付、毛利和减值持续改善，实际现金利润可能高于本口径，反之项目回款恶化或成本超支会使结果更差。

可能推翻判断的事实

最关键的是项目盈利和资产质量。综合毛利率仅13.74%，重型装备和钢结构毛利率为个位数，工程建设项目已经亏损；成本超支很容易穿透毛利。2025年信用及资产减值合计9.32亿元，应收账款与合同资产前五名余额31.03亿元，其中对应坏账及减值准备7.96亿元，个别客户或项目恶化会同时影响利润和现金。

第二是现金流反转。2025年的高经营现金流明显受存货、建造合同款和经营性应付项目变化推动；若新订单进入集中备料、客户预付款下降，或供应商付款加速，经营现金流可能显著低于当期利润。

第三是海外与融资约束。公司全球交付暴露于贸易政策、地区冲突、汇率和供应链波动；年内美元汇率波动已导致汇兑收益减少。PPP项目相关资产质押借款期限最长延伸至2050年，也意味着部分资产和现金流长期绑定。

数据口径与来源

核心财务和业务数据来自公司官网披露并经安永出具标准无保留意见的《上海振华重工（集团）股份有限公司2025年年度报告》（2026年4月16日）。市值、日期和PE TTM来自任务输入中的腾讯行情快照。金额均为人民币；比例和推导值由本研究依据年报原数计算。可持续现金利润是审慎估计，不是公司指引。
