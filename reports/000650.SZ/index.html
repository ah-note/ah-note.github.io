仁和药业进榜主要来自账上资金厚：市值约75.18亿元，owner_earnback 折后可剥离净现金约31.37亿元，覆盖市值约41.72%。便宜首先来自现金和存单/理财，而不是利润高增长；扣掉折后净现金后，经营业务购买价约43.81亿元。利润端采用2025年扣非归母净利润2.49亿元再打0.85折，折后现金利润约2.12亿元，控股回本约20.68年，并不短。最大前提是这些资金确实能按折扣口径剥离，同时OTC和大健康业务的扣非利润不再继续明显下滑。

资产和净资产

2025年末总资产77.35亿元，总负债8.03亿元，所有者权益69.32亿元，其中归母权益63.16亿元，少数股东权益6.16亿元，占所有者权益8.89%。这是一张低有息负债、资金类资产很重的资产负债表。

资金类资产44.96亿元，包括货币资金27.74亿元、银行理财10.69亿元、一年内到期大额存单1.39亿元、一年以上大额存单4.90亿元和少量权益/基金投资。经营类资产约25.07亿元，现实含义是客户赊销欠款和票据、药品和大健康产品库存、预付款、生产厂房设备、在建项目、租赁场地和经营无形资产。投资类资产约2.26亿元，主要是长期股权投资、投资性房地产和非流动权益工具。其他资产约5.06亿元，其中商誉3.91亿元是最重要项目。

owner_earnback 没把账上钱全额扣掉：先保留5亿元必要经营现金，再对现金、理财、存单、权益投资逐项折扣，并扣除租赁负债和1亿元税费/分红/处置摩擦，得到折后可剥离净现金31.37亿元。能扣的是超出日常经营需要、理论上可用于分红回购或偿债的现金、存单、理财和少量投资资产；不能全扣的是必要经营现金、条款不清的理财本金风险、期限较长的大额存单摩擦，以及投资性房地产等处置不确定资产。

业务和毛利

公司卖的是中西药、原料药、健康相关产品和线上大健康产品。年报披露药品业务以OTC为主，约占药品收入80%左右；主营收入来自药品和大健康类产品，利润贡献比例约65%和35%。

总收入35.36亿元，营业成本22.29亿元，毛利13.07亿元，毛利率36.96%。营业成本不是抽象的“成本”，主要对应药品和大健康产品的原材料、燃动力、生产人工和制造费用；其中原材料6.38亿元，占营业成本28.62%，是产品成本的大头。渠道分销收入34.88亿元，占98.63%，说明公司更像品牌和渠道驱动的OTC/大健康公司，而不是直营终端公司。

从毛利到归母净利润

35.36亿元收入扣22.29亿元营业成本后得到13.07亿元毛利。随后扣掉税金及附加0.38亿元、销售费用3.45亿元、管理费用2.56亿元、研发费用0.45亿元、财务费用0.00亿元。销售费用里职工薪酬2.53亿元、广告宣传0.48亿元、销售服务推广0.21亿元，现实含义是渠道销售人员、品牌宣传、终端推广和会议差旅开支；管理费用主要是总部和生产管理人员薪酬、折旧摊销、审计咨询信息费等。

利润表还有几项不能简单当作主业利润：其他收益0.94亿元主要来自政府补助；投资收益0.83亿元主要来自银行理财产品收益；公允价值变动收益0.25亿元来自交易性金融资产。由于理财、存单和投资资产本金已经在 owner_earnback 中作为可剥离净现金扣掉，它们对应的收益不能再完整计入可持续可分配现金利润，否则会把同一批资金的本金和收益双算。

减值端拖累较大：信用减值损失0.33亿元，主要是应收账款坏账；资产减值损失1.29亿元，其中商誉减值1.11亿元、存货跌价0.10亿元、无形资产减值0.06亿元。最终营业利润6.65亿元，所得税1.77亿元，净利润4.88亿元；少数股东损益0.94亿元后，归母净利润3.93亿元，扣非归母净利润2.49亿元。

利润和现金流

2025年经营现金流8.51亿元，高于净利润4.88亿元和归母净利润3.93亿元；扣除资本开支0.75亿元后，经营自由现金流7.77亿元。现金流好于利润，主要来自三类因素。

第一，减值、折旧摊销等非现金项目把会计利润压低，但不当期流出现金：资产减值1.29亿元、信用减值0.33亿元、固定资产折旧1.01亿元、无形资产摊销0.15亿元。第二，客户欠款和票据等经营性应收项目减少1.79亿元，说明以前压在客户或渠道账期里的钱回来了。第三，应付供应商、预收客户款、税费、员工薪酬等经营性应付增加0.78亿元，相当于公司多占用了供应链和客户的一部分资金。

负面项是存货增加0.49亿元。结合年报披露库存量同比增加4.04%、收入下降13.21%，库存不是最大风险，但说明药品和大健康产品备货没有随销售同步下降，后续若动销弱，存货跌价和渠道促销压力会继续影响毛利和现金流。

行业位置和上下游

仁和处于医药制造里的OTC药品和大健康消费品赛道。年报披露公司药品业务以OTC为主，药品和大健康产品是收入与利润核心；外部核查显示，这个赛道的终端环境并不宽松。商务部《2024年药品流通行业运行统计分析报告》显示，2024年全国七大类医药商品销售总额29470亿元，扣除不可比因素同比增长0.6%，药品零售市场6500亿元，同比增长1.3%，支持“药品流通进入低增速阶段”的判断，来源：https://yplt.mofcom.gov.cn/stat/attach/2024tjfxbg.pdf 。

2025年的药店终端更弱。医药魔方/ByDrug 汇总中康CMH数据称，2025年零售药店全品类销售规模5173亿元，同比下降2.2%；药品市场基本稳定但中成药下降7.2%，非药市场下降11.4%，线上渠道增速突出，来源：https://bydrug.pharmcube.com/news/detail/cedf7301ea216ee1a18ff48b7eedce3d 。这直接对应仁和2025年药品收入下降14.09%、健康相关产品收入下降11.41%、渠道分销仍占98.63%的报表表现：传统药店和分销渠道承压时，收入会先反映出来，销售费用下降则可能是公司收缩推广或优化费用。

政策方面，新华社2025年2月20日报道国家药监局2025年工作强调加强集采中选药品、委托生产药品以及网络销售环节等重点领域监管，来源：https://www.news.cn/health/20250220/fe34a2e70d774344bf071222277c7429/c.html 。仁和以OTC为主，直接院内集采暴露可能弱于处方药公司，但药价治理、网络售药合规、直播/电商推广合规会影响其渠道效率和费用投放。上游主要是原材料、燃动力、人工和制造费用；下游主要是经销商、药店、电商和终端消费者。前五大客户销售额6.57亿元，占18.56%，前五大供应商采购额3.83亿元，占18.88%，未显示单一客户或供应商绝对集中，但客户名称未公开。

投资和资本配置

2025年资本开支0.75亿元，显著低于2024年的2.86亿元；期末固定资产12.84亿元、在建工程0.54亿元、无形资产2.94亿元。这些资产对应工厂、设备、在建生产经营项目和药品/品牌/土地等经营权利。公司当年不是重资本扩张，更多是在存量经营资产上产生现金。

资金去向更重要的是金融资产。期末货币资金27.74亿元、交易性金融资产10.93亿元、一年内到期大额存单1.39亿元、一年以上大额存单4.90亿元。投资收益0.83亿元、交易性金融资产公允价值收益0.25亿元，说明现金池确实在贡献利润表收益；但本报告的回本口径已经把这些本金作为可剥离净现金扣掉，因此不能把理财收益完整当作经营业务利润。

投资类资产还有投资性房地产1.14亿元、长期股权投资0.32亿元、非流动权益工具约0.81亿元。商誉3.91亿元是资本配置留下的最大历史包袱；2025年商誉减值1.11亿元，且部分资产组预测期收入增长率为0或负值，说明过去并购形成的大健康和电商资产并非无风险资产。

回本率和估值含义

复用 owner_earnback 的主口径：市值75.18亿元，折后可剥离净现金31.37亿元，经营业务购买价 = 市值 - 折后净现金 = 43.81亿元。折前可分配现金利润使用2025年扣非归母净利润2.49亿元，再按0.85折扣，得到折后可持续可分配现金利润2.12亿元。

控股回本年数 = 43.81亿元 / 2.12亿元 = 20.68年。控股回本率 = 2.12亿元 / 43.81亿元 = 4.84%。市值/折后现金利润 = 75.18亿元 / 2.12亿元 = 35.48年，现金利润收益率 = 2.12亿元 / 75.18亿元 = 2.82%。

这个回本数最依赖三个前提：第一，31.37亿元折后净现金可以真实剥离，理财和存单不存在比已采用折扣更强的限制；第二，2025年扣非归母净利润2.49亿元不是周期低点后的继续下台阶，而是可维持利润基数；第三，政府补助、理财收益、公允价值收益和商誉减值等非经营项不会被误当作主业现金利润。

风险判断

高：收入和扣非利润继续下滑。 行业背景是药品流通低增速、药店终端承压、线上渠道分流和价格监管强化。历史变化上，公司2025年收入同比下降13.21%，扣非归母净利润同比下降25.51%；药品收入下降14.09%，健康相关产品下降11.41%。公司数字证据显示渠道分销占98.63%，对传统渠道和终端动销依赖高。发生概率评为中，影响评为高，综合为高。主观判断是：当前回本分母已经用2025年扣非利润并打折，但如果收入继续下滑，2.12亿元折后现金利润仍可能偏高。

中：商誉和资产减值继续侵蚀利润。 行业背景是OTC和大健康品牌竞争加剧，电商价格透明化削弱收购资产组的盈利预期。历史变化上，2025年资产减值损失1.29亿元，其中商誉减值1.11亿元；期末商誉仍有3.91亿元。公司商誉测试中，部分资产组预测期增长率为0或负增长。发生概率中，影响中，综合中。主观判断是：减值短期不直接流出现金，但会说明过去并购业务的盈利能力弱于账面假设，继续发生会压低归母利润和市场信心。

中：资金类资产剥离折扣不足。 行业背景是上市公司资金分配受理财条款、存单期限、税费、少数股东和经营周转影响。公司期末资金类资产44.96亿元，但银行理财10.69亿元未逐项披露保本和赎回条款，一年以上大额存单4.90亿元也未披露完整期限。发生概率中，影响中，综合中。主观判断是：owner_earnback 已做折扣和摩擦扣除，口径偏保守；但若实际限制更强，折后净现金会下降，经营业务购买价会上升。

中：药品监管、集采和网络售药合规压力。 行业背景是国家药监局把集采中选药品、委托生产药品、网络销售环节列为2025年监管重点。公司自身年报也提示行业政策调整、市场竞争和招标价格下滑风险。公司数字上，销售费用3.45亿元，其中销售人员薪酬、广告宣传和销售服务推广合计占主要部分，说明渠道和推广合规会直接影响利润。发生概率中，影响中，综合中。主观判断是：仁和OTC属性降低了部分院内集采冲击，但线上售药和零售终端监管会长期影响渠道效率。

已尝试但仍不可确认：银行理财逐项条款。 已查年报交易性金融资产附注、owner_earnback结果和公开网页，仍不能确认每一笔理财的保本性质、期限和赎回限制，因为公开资料未披露合同明细。它对结论的影响是：若条款弱于当前0.65折扣假设，折后净现金和回本率需要下修。
