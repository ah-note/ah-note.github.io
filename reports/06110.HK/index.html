结论

滔搏仍是一台有现金产出的全国运动鞋服零售机器，但已从扩张期进入“收缩门店、清库存、保利润”的成熟调整期。最新完整财年收入257.4亿元，较两年前的289.3亿元低11.0%；同期毛利率由41.8%降至38.0%，EBIT由27.9亿元降至15.2亿元。门店、人员和租赁成本收缩把EBIT率守在5.9%，却没有扭转核心盈利台阶下移。真正需要判断的不是短期销售何时反弹，而是线上占比提高和促销常态化后，38%左右毛利率是否已成为新常态。

现金质量比利润表看上去更好。最新年度经营现金流27.3亿元，库存减少5.18亿元；按经营租赁口径将租赁本金纳入资本开支后，实际FCFF约13.2亿元。公司没有证据充分、需要另行高估值的成长项目，因此本报告以稳定经营收益12.9亿元的八倍作为经营资产固定标尺，得经营资产价值约103亿元；加多余现金22.6亿元和非经营投资0.46亿元、扣银行借款19.7亿元后，普通股基准价值约107亿元，即每股约1.97港元。输入未提供有效市场快照，本报告不计算当前价格折溢价，也不给买卖建议。

客户为何付款，订单怎样形成

消费者为Nike、Adidas及其他运动品牌的鞋服产品付款，滔搏提供的不是制造，而是品牌触达中国消费者所需的门店位置、库存调拨、销售人员、会员运营和线上履约。最新年度零售收入224.1亿元，占总收入87.0%；批发收入31.6亿元，占12.3%；商业空间特许经营费和电竞收入合计仅1.65亿元。公司在财务报告中只识别一个报告分部，本报告按交易对象和履约方式拆成全渠道消费者零售、下游零售商批发、商业空间特许经营服务及电子竞技运营四项业务。《Annual Report 2025/26》，PDF pp.16、86。

零售订单由实体门店、电商平台、微信私域、本地生活和即时零售共同获得。期末公司有4,360家直营店、超过700个抖音及视频号官方账号、约3,700个小程序门店，约3,800家实体店接入即时零售。累计用户9,290万；会员贡献线下门店及微信小程序零售额的91.7%。这说明会员关系和门店库存是同一销售系统，而不是可以分开估值的“线上业务”。《Annual Report 2025/26》，PDF pp.10–13。

批发订单来自下游零售商，收入规模较小且下降更快，最新年度同比下降16.6%。其毛利低于直接零售，但无需承担同等强度的门店租金和一线销售人员。特许经营服务是向零售商和分销商提供商业空间；电竞业务有独立牌照及合同资产，但最新收入只有0.41亿元，尚不足以证明其稳定盈利能力。

供给、交付与议价关系

供给端高度集中。Nike与Adidas合计贡献收入86.7%；前五大供应商占采购94.7%，最大供应商占62.7%。与之相比，前五大客户合计收入不到3.8%。滔搏对消费者和下游客户高度分散，却对少数品牌供货、产品热度、折扣政策和渠道授权高度依赖。因此全国门店和九千多万用户提高了滔搏对品牌的服务价值，却不能消除品牌方的议价权。《Annual Report 2025/26》，PDF pp.16、23。

商品由全国库存系统在门店和线上渠道之间流转。公司将实体店定义为获客、私域沉淀、即时履约和内容营销的共同节点；这提高库存售出的路径数量，也让门店不仅靠自然客流。但线上运动鞋服促销更激烈、折扣更深，线上占比提高是最新年度毛利率再降0.4个百分点的主要原因。换言之，全渠道在收入端减缓了线下客流下降，在毛利端却带来新的折扣压力。《Annual Report 2025/26》，PDF pp.9–11、17。

定价、成本和利润形成

滔搏面对的是品牌建议价格、市场促销和库存季节共同约束的定价体系。消费者可跨平台比价，旧款库存又会随产品周期迅速贬值，公司无法仅靠门店规模维持价格。近三年毛利率41.8%、38.4%和38.0%的变化，比收入下降更能说明议价环境恶化。库存可变现净值也是审计关键事项；管理层必须依据预计售价和销售费用计提跌价，竞争者促销或消费者偏好变化都可能迅速改变估值。《Annual Report 2023/24》，PDF pp.50–54；《Annual Report 2025/26》，PDF pp.51–56、85。

期间费用的主体是商场扣点及租赁、使用权资产折旧、销售人员薪酬、门店运营、物流和线上平台服务费。最新年度销售及分销费用73.5亿元，同比减少7.5%；一般及行政费用9.93亿元基本持平。公司同期净关660家店，员工由27,279人降至22,376人，费用率因而下降0.7个百分点至32.4%。成本收缩已很显著，未来若收入继续下降，可继续削减的固定成本空间会比过去两年更有限。《Annual Report 2025/26》，PDF pp.10、17–20。

最新业务利润拆分不是公司披露，而是在合并总量约束下的基准估计。全渠道零售贡献约10.2亿元NOPAT及23.5亿元经营现金流；批发约2.90亿元NOPAT；特许经营约0.37亿元NOPAT；电竞约亏损0.69亿元NOPAT。零售之外的成本和现金流没有公开分拆，可信度较低；后续若出现渠道利润、门店级盈利或电竞独立财务数据，应直接推翻这些分配，而不应把估计的小数精度当作事实。

现金、库存和维持投入

期末库存54.9亿元，仍是最大的经营资产，约相当于131天销售成本。库存同比下降8.6%，快于收入4.7%的降幅，说明清理有效；但贸易应收款由7.52亿元升至13.4亿元。公司披露商场专柜和电商平台通常分别在30天和15天内回款，平均应收周转天数仅由14.1天升至14.8天，因此年末应收跃升更像结算时点和渠道组合变化，而不是已经证实的信用恶化，仍需下一期现金回收验证。《Annual Report 2025/26》，PDF pp.4、17、104。

经营现金流从31.3亿元升至37.6亿元后回落至27.3亿元。2024年度的21.4亿元FCFF受营运资金释放8.84亿元推动，不代表可持续盈利；最新年度营运资金仅释放0.52亿元，13.2亿元FCFF更接近当前盈利能力。公司披露的长期资产购置现金仅2.84亿元，但门店租赁本金也是取得经营场所的持续现金投入。最新租赁付款10.90亿元中约0.66亿元为利息，余下10.25亿元纳入资本开支；因此现金资本开支合计约13.1亿元，而不是只看固定资产和无形资产购置。《Annual Report 2025/26》，PDF pp.61、88、98–110。

开拓性资本开支没有法定分拆。本报告根据电竞牌照、专业跑步及户外品牌试点规模，将近三年开拓性长期投入基准估计为0.20亿元、0.25亿元和0.30亿元，其余均视作维持现有零售网络、装修设备和租赁权的主营投入。这个估计只回答“公司仍在用少量现金试新业务”，不能说明项目价值；若公司披露新品牌门店、项目亏损或独立资本预算，应重新划分。

资本效率和难复制环节

投入资本由库存和应收形成的经营性营运资金、门店租赁和装修形成的长期净资产，以及约14天现金经营成本对应的必要现金组成；商誉另行剔除。三年投入资本从86.3亿元降至74.9亿元，ROIC由27.0%降至16.0%后回升至16.8%。回升主要来自库存、门店和使用权资产收缩，并非利润增长，因此只能说明资本占用变轻，不能单独证明竞争优势增强。

真正难复制的是全国可调拨库存、品牌合作、门店触点、会员数据和一线执行同时存在的系统。单独复制门店容易，单独购买线上流量也容易；难点在于把数千家门店变成同一库存池、即时履约节点和会员运营入口。但这套能力的经济价值必须最终体现为稳定毛利、库存周转和费用效率。若毛利持续被线上折扣侵蚀，它会变成维持市场份额的必要条件，而不是带来超额利润的护城河。

开拓业务与当前阶段

公司正引入Norrøna、norda、Soar和Ciele等专业户外及跑步品牌，并运营ektos跑步生活方式概念店；这能训练本地内容、运动社群和高端品牌运营能力，却没有披露独立收入、利润、门店数或资金需求。电竞同样只有0.41亿元收入和0.23亿元相关牌照合同账面净值。两类业务均处于能力建设和试验阶段，本报告将开拓项目价值计零：这不是断言其没有价值，而是不把未经验证的选择权预先支付给估值。《Annual Report 2025/26》，PDF pp.6、13、16、100。

主营业务本身则已处于成熟收缩期。四年间门店由6,565家降至4,360家，单店面积仍增加，但最新年度总销售面积再降9.7%。资本开支同比下降24.0%，新开店201家、关店861家。稳定状态不应假设重新高速开店，而应假设约260亿元收入、38.0%毛利率、6.15% EBIT率及零永久营运资金增长。

股东资金可达性与资本配置

期末短期质押存款、银行结余和现金合计31.4亿元，短期借款19.7亿元，净现金11.7亿元。按约14天现金经营成本保留8.79亿元必要现金后，多余现金为22.6亿元；由于其中10.7亿元质押存款对应有担保借款，本报告把现金和借款分别加回与扣除，净效应一致。另有0.46亿元非上市时尚业务优先股投资按账面公允价值计入非经营资产。《Annual Report 2025/26》，PDF pp.19–20、58–59、101、105–107。

资金确实有到达股东的历史记录：最新年度拟付全年股息每股0.28元人民币，派息率137.1%；上市以来累计派息146亿元，累计派息率107.3%。不过高派息同时意味着股东回报越来越依赖现有现金与成熟业务，而不是利润再投资。物流服务和物业租赁来自Belle International关联方，最新年度分别支付4.76亿元和0.22亿元；物流服务按成本加5%税前加成，独立董事确认条款属正常商业条件。关联交易规模不至于单独改写价值，但供应链高度集中与关联服务并存，要求持续检查价格、服务质量和替代性。《Annual Report 2025/26》，PDF pp.5、9、27–29、90、111。

稳定状态和普通股价值

稳定状态采用收入260亿元、毛利率38.0%、期间经营费用82.8亿元、EBIT 16.0亿元、经营现金税2.58亿元、折旧摊销12.5亿元、主营资本开支13.0亿元和零营运资金永久增加。所得税、毛利和费用均靠近最新年度，不把2023/24较高毛利率或2024/25大额营运资金释放外推。由此得到稳定经营收益12.9亿元。

证据不足以建立逐年成长FCFF和明确到达稳定状态的日期，因此使用八倍固定标尺：经营资产价值约103亿元。资产桥加入多余现金22.6亿元和非经营投资0.46亿元，扣除短期借款19.7亿元，少数股东和其他优先索偿为零，得到普通股基准价值约107亿元。期末完全摊薄股份62.01亿股；采用年报拟派股息折算隐含的1元人民币兑1.143港元，每股基准价值约1.97港元，六成安全边际价格约1.18港元。后者是统一估值纪律，不是买入建议。

主要风险、反证和观察点

  • 毛利风险：线上促销和品牌直营若使毛利率连续两年低于36%，当前稳定经营收益偏高；若毛利率重回40%以上且库存周转不恶化，则偏低。
  • 品牌集中风险：最大供应商占采购62.7%。核心品牌削减授权、提高采购要求或扩大直营，会同时冲击收入、毛利和库存；反证是滔搏获得更深独家合作或其他品牌形成有规模的利润贡献。
  • 门店收缩风险：关店当前释放租赁和人员成本，但若销售面积降幅持续大于收入降幅、单店效率仍不能提升，网络优势可能开始削弱。
  • 库存与应收风险：库存跌价是审计关键事项，贸易应收年末显著增加。下一期需同时验证库存天数、折扣深度和应收回款，不能只看经营现金流总额。
  • 开拓项目风险：专业品牌、ektos和电竞若持续消耗现金却不披露独立单位经济性，应提高开拓性资本开支并继续将项目价值计零；若形成可核验收入、利润、复购和资本预算，才可单独计值。
  • 现金可达性：历史高派息支持现金归属普通股，但境内资金汇出受外汇和预提税规则约束。若分红政策改变或现金长期沉淀，应对多余现金施加可达性折扣。

口径与估计说明

任务中的2023、2024、2025为研究展示年度；对应法定财务期间分别为截至2024年2月29日、2025年2月28日和2026年2月28日止年度。输入的报告期为2025年12月31日，但材料清单明确提供2025/26完整年报，本报告将其作为“2025”最新完整年度，同时在结构化底稿保留每项事实的真实期间和PDF页码，避免把12月末误作公司法定年结日。

EBIT采用合并经营利润；期间经营费用为毛利减EBIT的净额，因此包含其他收入和应收减值影响。经营现金税按披露所得税费用相对税前利润的比例缩放至EBIT。租赁统一按经营口径：使用权资产进入经营长期资产，租赁负债从其净额扣除，租赁本金进入现金资本开支，股权价值桥不再重复扣租赁负债。必要现金按约14天现金经营成本估计；商誉约10.0亿元从投入资本剔除，品牌、渠道和规模能力的价值只由稳定经营收益反推。
