东方精工（002611.SZ）2025年度经营质量与控股回本研究

报告期为2025年12月31日，行情口径为2026年7月31日市值194.28亿元、PE TTM 4.65。金额除特别说明外均为人民币。

结论先行

东方精工是普通经营型制造公司，普通控股回本模型适用。它不是单一的“纸箱设备厂”：约三分之二收入来自Fosber体系的瓦楞纸板生产线，约两成来自百胜动力的舷外机和通机，其余主要是纸箱印刷包装设备。公司2025年收入52.29亿元、同比增长9.43%，但三大产品毛利率都下降；归母净利润7.25亿元、同比增长44.88%，其中证券投资收益和公允价值变动合计约2.49亿元，扣非归母净利润反而同比下降1.49%。因此表面利润增长不能直接外推为主业增长。

现金质量好于单看扣非利润的印象：经营现金流8.74亿元，减去购建长期资产支出2.10亿元后，经营自由现金流约6.64亿元。不过经营应付款增加4.08亿元推高了当年现金流，不能把6.64亿元全部视为稳定可分配水平。本报告以扣非归母净利润5.19亿元和自由现金流交叉验证，审慎采用5.00亿元折后可持续现金利润。

账面资金较厚，但并非全部能拿走。将现金、理财和高波动证券按流动性折价，再全额扣除借款、租赁负债及少数股东期权回购义务，得到折后可剥离净现金约18.66亿元。以194.28亿元市值计算，经营业务购买价约175.62亿元，控股回本约35.1年；市值/折后现金利润约38.9倍。这个结果与输入PE TTM 4.65差异显著，说明滚动期利润很可能受投资或处置事项影响，PE不能代替持续经营现金利润判断。

公司怎么赚钱

公司向纸包装企业销售瓦楞纸板生产线、纸箱印刷设备以及安装、维修和配件服务，并通过百胜动力销售舷外机、通机等水上动力产品。设备业务通常在交付前收取20%—90%款项，机器交付时确认销售收入，服务收入在履约期间确认。直销占收入79.67%，海外收入占79.12%，所以技术、品牌、海外销售服务网络和交付能力是盈利基础，应收、存货与工厂设备则是做生意必须占用的资产。

2025年各产品表现分化：

  • 瓦楞纸板生产线收入35.21亿元，占67.34%，毛利率29.63%。Fosber集团收入约31.44亿元，同比增长约5.66%，仍是规模和利润主体。
  • 瓦楞纸箱印刷包装设备收入6.92亿元，同比下降14.63%，毛利率27.89%，同比下降6.95个百分点，是当年最明显的压力点。
  • 水上动力及通机收入10.16亿元，同比增长34.14%，毛利率19.14%。百胜动力净利润约1.08亿元，同比增长33%，增长快但毛利率低于包装装备。

公司称Fosber是全球高端瓦楞纸板生产线综合实力最强的两家公司之一，在北美市场具有领先位置；东方精工纸箱印刷线销往60多个国家，万德数科处于国内数码印刷设备第一梯队。百胜动力则在国产大马力舷外机上形成技术突破。上述行业位置主要是公司年报陈述，能够说明业务基础，但不是独立市场份额验证。

经营数字说明什么

2025年营业成本37.98亿元，毛利14.31亿元，综合毛利率27.36%，较上年下降2.72个百分点。从毛利到营业利润主要扣除了管理费用3.90亿元、销售费用1.80亿元和研发费用0.98亿元；财务费用为负0.13亿元，厚现金带来的利息收入提供了帮助。

营业利润9.45亿元中还包含投资收益1.47亿元和公允价值变动收益1.02亿元，同时发生资产减值0.68亿元。归母净利润7.25亿元相当于净利率13.87%，但扣非归母净利润只有5.19亿元。主业更接近“稳定但毛利承压”，而不是报表净利润所显示的高速增长。

经营现金流8.74亿元，高于归母净利润；自由现金流约6.64亿元。现金流改善来自销售回款增加，但现金流量表补充资料同时显示，存货增加消耗1.01亿元、经营应收增加消耗2.21亿元，经营应付增加贡献4.08亿元。换句话说，回款总体改善是真实的，但供应链负债扩张也贡献了现金，未来可能回摆。

资产负债对应哪些真实东西

总资产87.24亿元、总负债26.91亿元、归母权益57.74亿元，少数股东权益约2.59亿元。资产负债率不高，融资债务也不重。

资金端包括货币资金20.79亿元和交易性金融资产7.67亿元。货币资金中现金及现金等价物19.94亿元；另有0.85亿元受限，且0.72亿元境外资金汇回受限。交易性金融资产中，银行理财3.53亿元相对接近现金，股票基金3.33亿元、资管和信托0.81亿元则存在更明显的价格和退出风险。

经营资产主要是应收账款9.52亿元、存货11.19亿元、固定资产10.84亿元、在建工程1.96亿元和无形资产3.67亿元。它们对应设备交付、客户账期、原材料和国内外工厂，不应从市值中直接扣掉。应收同比增加约2.06亿元；存货跌价和商誉减值使当年资产减值损失达到0.68亿元，需要持续观察。

长期股权投资3.03亿元和其他非流动金融资产8.17亿元，主要涉及机器人和硬科技少数股权。这些资产可能有价值，但退出时间、估值和战略约束不清楚，本次不把它们算作可剥离现金。

负债端，应付账款和应付票据合计11.77亿元，是采购形成的供应链负债；合同负债4.59亿元是客户预付款，对应2026年待交付设备和服务，不能当成自由现金。借款、租赁负债合计约4.06亿元，另有0.94亿元衍生金融负债，主要是少数股东期权回购义务，控股口径均全额扣除。

控股回本计算

折后资金按以下原则处理：现金及现金等价物按90%计17.95亿元；受限资金按50%计0.42亿元；银行理财按90%计3.17亿元；股票、基金、资管及信托分类折价后计2.12亿元；再扣除融资、租赁及衍生金融负债5.00亿元。合计折后可剥离净现金18.66亿元。

持续现金利润从三组数字交叉判断：归母净利润7.25亿元、扣非归母净利润5.19亿元、经营自由现金流6.64亿元。考虑证券投资波动、经营应付款增加以及维持性资本开支，本报告取5.00亿元。

计算结果为：

经营业务购买价 = 194.28 - 18.66 = 175.62亿元
控股回本年数   = 175.62 / 5.00 = 35.1年
市值/现金利润  = 194.28 / 5.00 = 38.9倍
折后净现金/市值 = 9.61%

这不是目标价或买卖建议，只是以全资收购、剥离非经营资金后，用保守持续现金利润回收经营业务购买价的估算。若长期产业投资能够高价退出，当前计算偏保守；若2025年营运资金改善不能持续，或毛利继续下降，5亿元现金利润仍可能偏高。

分红能力

公司2025年第一季度已实施现金分红1.5825亿元。年报最初拟不进行年度分配，随后方案调整为每10股派0.42元，按约12.17亿股估算约0.511亿元，并于2026年股东会通过实施。两次合计约2.094亿元，若作为下一周期基准，对当前市值的预测分红率约1.08%。

经营现金流足以覆盖这一规模，但预测不是承诺：2026年中期分红方案、股本变化、投资计划和母公司可分配利润都可能改变实际金额。

可能推翻判断的事实

海外收入占近八成，欧美纸包装客户资本开支、汇率和贸易政策会直接影响Fosber订单。三大产品毛利率同时下降，若竞争和产品结构压力延续，收入增长未必转化为利润。应收和存货规模上升，经营现金流又受应付增加支持，未来回款或供应链付款变化可能压低现金利润。此外，投资收益、公允价值变动和长期股权投资退出会让单期利润及PE剧烈波动，应把主业利润与投资结果分开观察。

数据口径与来源

核心财务数字来自《广东东方精工科技股份有限公司2025年年度报告全文》（公司官网PDF，与巨潮资讯同日披露），分红来自公司在巨潮资讯披露的权益分派公告；市值和PE来自本次输入的Tencent行情快照。行情未用交易所逐笔数据复核，持续现金利润也只基于2025单年审计数据进行审慎估计，这是本报告的主要限制。
