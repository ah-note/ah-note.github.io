# 公开发布边界

AH Note是公司研究唯一的读者入口。`stock_report`提供已校验研究成果和历史追溯，但其Git文件地址不作为报告交付链接。

当前公司研究协议为`stock-research-analysis-v2`。站点只接纳五项Sol核心自审全部通过、关键计算字段完整且正文存在的结果；同一证券选择最新报告期，同一报告期优先当前协议。站点只做协议映射和Markdown展示，不修改经营数字、估值或中心判断。

`/reports/<code>/`展示当前公司研究。`/research/<code>/<version>/`保留通过独立注册表、审阅状态和正文哈希验证的不可变历史深度研报；两条路径都属于AH Note公开站点，但来源准入不同。

远端发布服务使用干净的`stock_report`镜像，先快进同步，再检测稳定且可发布的成果，串行构建、提交和推送。发布失败不能推进监听状态，站点工作树不允许混入运行缓存。

深度研报列表页直接进入文章列表，不展示宣传性页头。该要求固化在生成模板和回归测试中，不能只修改生成HTML。
