# 公开发布边界

AH Note是公司研究唯一的读者入口。`stock_report`提供已校验研究成果和历史追溯，但其Git文件地址不作为报告交付链接。

当前公司研究协议为`stock-research-analysis-v3`，并继续读取尚未重跑的v2结果。站点只接纳五项Sol核心自审全部通过、关键计算字段完整且正文存在的结果；v3还要求3—5年连续历史和非空的最新年度业务拆分。同一证券选择最新报告期，同一报告期按v3、v2、统一v1和旧版顺序取最高协议。站点只做协议映射和Markdown展示，不修改经营数字、估值或中心判断。

`/reports/<code>/`展示当前公司研究。`/research/`聚合当前协议报告与历史深度研报：当前报告链接到`/reports/<code>/`，历史报告仍链接到`/research/<code>/<version>/`。同一证券、同一报告期重复时优先当前协议。历史地址继续保留通过独立注册表、审阅状态和正文哈希验证的不可变文章；两类内容都属于AH Note公开站点，但来源准入不同。

远端发布服务使用干净的`stock_report`镜像，先快进同步，再检测稳定且可发布的成果。每次发布从远端最新`main`创建一次性 Git worktree，在其中完成构建、提交和推送；输入、构建或推送失败时销毁整个 worktree，不能污染常驻站点 checkout，也不能推进监听状态。推送失败最多退避重试三次，每次重新读取远端基线并构建。

研究列表页直接进入文章列表，不展示宣传性页头。该要求固化在生成模板和回归测试中，不能只修改生成HTML。

`/industries/`读取`stock_analysis`的版本化 A/H 全市场行业快照，不从报告正文反向猜测行业。站点构建时把分类树、发行人、证券别名、排除状态和代表公司压缩为一份公开 JSON；前端只负责搜索和层级展示，不改写分类事实。

公开行业树折叠连续同名的父子节点，例如底层的“能源→煤炭→煤炭→煤炭”显示为“能源→煤炭”。折叠只影响展示节点和导航，源 HSICS 层级、代码和发行人主分类不变。

发布器是常驻 Python 进程。发布前如果站点仓快进到了新提交，必须先自重启重新加载模板，再生成页面，避免内存中的旧模板覆盖新导航。
