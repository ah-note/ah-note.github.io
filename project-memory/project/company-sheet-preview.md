# 公司资料页原型边界

`/value-line/`保留静态原型与共享渲染资源；正式读者入口已迁移到`/capital/`。本站消费分析仓生成并通过校验的独立年度JSON，不负责运行模型，也不据此恢复股票分析队列。通用发布脚本按内容哈希安装年度文件，同时更新公司年度清单和资本表目录。

用户偏好紧凑的资料表：信息优先，不放宣传标题、卡片式仪表盘和自说明正文。资本表12标准字段常显，资本活动默认大项目合计、子项折叠。年份按钮控制原位明细列，两表年份联动，允许多年份同时展开；同一子项目跨年展开联动，子字段取并集形成主表真实共享行，缺项空白、零与缺失区分。表未占满时居中，随年数向两侧扩展，超宽水平滚动。简版入口已移除；口径、来源、异常和限制留本页折叠区，不跳转。旧版notes.html和标签保留。

入口与演进：

- `/value-line/`：三年公司对比阅读原型；不冒充十年历史或实际历史EPS。
- `/value-line/classic/`：2017年Disney历史样页结构试验；缺少的图表序列保留占位，不猜造曲线。
- `/value-line/berun-assets/`：通用型资产流转表及标准字典，见该目录standard.md。
- `/value-line/tan-assets/`：复用同一12项资产字典与13类经济变动；同页增加2025年资本活动表。
- `/value-line/tan-assets/compare.html`：优先读取annual-manifest.json列出的独立年度文件，现已接入谭木匠2021—2025五个真实`capital-statement-v3`年度。v3嵌入同一`capital-display-v1`注册表；主表和展开行只显示注册的中文经济字段，财报原始科目、页码、映射贡献、算式和理由只留折叠证据区。2024等年度因资本采购结算未披露，经营净资产小计保持缺失，但合并及归母净资产使用法定控制数展示；页面不把未知子项当零。清单尚不存在时仅404回退原2024/2025矩阵，其他加载或协议错误不可静默回退。旧两表以`asset-capital-v1-20260910`标签保存在e6a290f9，并已推送。
- `/capital/`：正式资本表目录；首批包含谭木匠2021—2025和环球烟草2026。
- `/capital/<code>/`：公司多年资本表；复用同一渲染器，v3/v4遵循同一`capital-display-v1`显示契约。

年度JSON必须同公司、币种且年份不重复；相邻年期初/期末不一致保留两边值并提示，不擅自替换。网页不重新推断经营分类，来源、估计和校验差额随数据保留。新增年度不要求重新生成公司所有年度，资料和解释可以复用相邻年份。

同一公司同时存在不同显示注册表版本时，页面以最新报告期的完整注册表选择一致期间展示，并明确提示暂未混合的旧口径期间；不得因混合版本让整页空白，也不得把旧字段静默套入新字段。待旧期间完成确定性迁移后，再恢复跨版本历史序列。

`scripts/import_capital_year.py`接入可信验收、带明确起止日的v3/v4历史文件和当前v5文件，内容哈希命名并保留旧版本，清单按报告截止日切换引用；所有版本均要求事实账本、映射和完整显示注册表，扩展字段不超过5个。`scripts/publish_capital_statement.py`在此基础上生成正式目录和公司页。五个谭木匠v3期间由已完成结果确定性补充日期，没有重跑模型；人工复核纠正2025年2千元理财处置损失的经济分类，五期均为0个扩展字段。环球烟草v4历史结果明确标注2025-04-01至2026-03-31，且五项网页异常已改为中文。页面不把闭合误写成全部已解释。

资产口径：经营净资产＋非经营资产−非经营负债＝合并净资产，再分归母和少数权益。经营结算占款与融资义务分开，但不能仅凭账龄把应付当融资。必要现金未分配时不得宣称全为可分配现金；现金与存款内部转存抵消，理财另列。未知变动明确保留差额，不能靠补造交易闭合。

资本活动不再用期初期末列。净资产形成和资金收付与配置分区汇总：经营盈余排除折旧及资产损失，随后分别扣回；资本开支、投资本金和借还款不是损益。税后折旧前盈余仍是权责发生制指标，不叫实收现金。谭木匠所得税的经济归属是显式比例估计，不反推资产表各税款归属。两块分别闭合到净资产增量和现金与存款增量，不能相加。

资产构成不能在第一列嵌套一张多年表；构成展开后必须成为主表中的共享子行，按年份并集排列并直接落在各年余额列下。与年度变动同时展开时，在该年度的两列变动区保留对应跨列空位，使后续年末余额继续对齐。静态资源统一使用同一版本参数，避免浏览器混载新渲染器与旧事件脚本。

资本活动年份下不再重复显示“净贡献／净收付”。异常区只呈现重要异常和一次性事项：有相关标准字段可作比较时，低于该字段绝对金额3%的事项及相邻年勾稽差异不进入异常区；完整警告仍保留在折叠证据区。完整网页字段白名单由分析bundle的机器注册表单点维护；v3网页从年度数据读取注册表，不另存一套前端名称。扩展只能挂在既有父字段下，每份年报最多5个，零扩展是正常状态。

年度币种严格采用该份财报自身的呈报货币，以ISO代码显示；`RMB`仅规范为`CNY`，不能由上市地或交易币种替换。谭木匠五份财报均为CNY，因此两张表均显示`CNY 亿元`。

验证用纯函数、数据闭合、脚本模拟加载和HTTP响应；2021—2024真实v2接入后已在Chrome核对折叠态、经营周转构成及2024年度联动展开，布局和字段对齐正常。保持现有本地AH Note预览流程，不为技能默认托管步骤创建第二个网站。早期记录“Sites接口不可用”不是持续事实：后续会话已发现接口可用，是否发布取决于授权与项目边界。
