龙版传媒进入观察，不是因为经营利润特别便宜，而是账上资金厚：市值40.93亿元，owner_earnback折后可剥离净现金19.51亿元，扣现金后的经营业务购买价21.42亿元。利润端没有按报表归母净利润2.24亿元直接外推，而是复用回本专题口径：扣非利润扣除资金利息后的三年中位数再打八折，得到折后可持续可分配现金利润1.21亿元。这个口径下控股回本17.72年，正式分类仍是 liquidation_watch，不是纯利润便宜。最大前提是教材教辅现金利润不继续明显下滑，同时定存、理财和必要经营现金的折扣没有过度乐观。

资产和净资产

2025年末公司总资产57.76亿元，总负债18.71亿元，所有者权益和归母权益均为39.05亿元，少数股东权益为0，少数股东权益占比0.00%。

资产端按经营含义重分类，资金类资产30.09亿元，主要是货币资金23.51亿元和交易性金融资产6.58亿元；货币资金里包括现金及现金等价物3.28亿元、单位定期存款本金19.41亿元、定存利息0.77亿元，以及共管、冻结和平台店铺余额552万元。经营资产约27.60亿元，主要是固定资产21.51亿元、无形资产2.45亿元、存货1.80亿元、在建工程0.77亿元、应收账款0.58亿元，另有预付款、其他应收、长期待摊等较小项目。投资类资产0.08亿元，主要是长期股权投资和其他权益工具投资。其他资产仅递延所得税资产6.41万元。

负债端没有短期借款、长期借款、应付债券、一年内到期非流动负债和租赁负债，融资负债为0。经营性流动负债7.63亿元，包括应付账款3.28亿元、预收款和合同负债合计2.49亿元、应付职工薪酬1.25亿元、其他应付款0.47亿元以及税费和其他流动负债。其他负债11.09亿元，其中长期应付职工薪酬10.59亿元最重要，它不是银行债，但代表退休、内退、遗属补贴、补充医疗等长期福利现金义务。

可剥离现金完全沿用 owner_earnback 折扣：现金及现金等价物按0.90折，单位定期存款本金和利息按0.70折，R1/R2银行理财按0.75折；共管、冻结、平台店铺余额不剥离；另保留2.50亿元必要经营现金。折后可剥离净现金为19.51亿元。已经作为可剥离净现金扣掉的现金、定存和理财，其利息、投资收益和公允价值收益不能再完整计入可分配现金利润，否则会把本金和收益双算。

业务和毛利

公司是黑龙江出版发行平台，主营出版、发行、印刷物资及相关文化教育服务。2025年营业收入15.18亿元，营业成本8.86亿元，毛利6.32亿元，综合毛利率41.61%。主营业务收入14.60亿元，其中教材教辅10.29亿元，占主营收入70.46%，营业成本5.24亿元，毛利率49.04%；一般图书3.85亿元，占26.36%，成本3.11亿元，毛利率19.30%；物资贸易0.11亿元，毛利率3.07%；其他业务0.36亿元，毛利率40.93%。

教材教辅是这门生意的现金核心。它依靠黑龙江省教育厅目录、学校征订、新华书店系统配送和出版社提印来运转，客户付款和合同负债带有教育周期特征。2025年教材教辅收入同比下降18.85%，公司年报解释为政策及学生人数减少影响；但毛利率仍有49.04%，说明这一块收入少了会直接影响利润分母。一般图书收入增长38.48%，但成本增长60.59%，毛利率降至19.30%，更像用低毛利品类补收入缺口。

成本不是抽象的“营业成本”。出版成本里有纸张、印刷、租型、稿酬、编录经费和外购图书；发行成本主要是外购图书和渠道配送；印刷与物资贸易则对应纸张、印刷耗材、直接人工和制造费用。2025年主营成本随收入下降而减少，但毛利率较上年下降2.13个百分点，说明低毛利一般图书和省外业务占比提高后，整体经济性被摊薄。

从毛利到归母净利润

15.18亿元收入减8.86亿元成本，得到6.32亿元毛利。继续扣税金及附加0.29亿元、销售费用1.77亿元、管理费用2.82亿元、研发费用0.04亿元；财务费用为-0.26亿元，原因是利息收入0.48亿元大于离职后福利利息0.22亿元和手续费。再加其他收益0.29亿元、投资收益0.01亿元、公允价值变动收益0.13亿元，扣信用减值0.01亿元和资产减值0.01亿元，营业利润为2.08亿元。营业外收入净额贡献约0.16亿元，利润总额2.24亿元，所得税仅15.48万元，净利润和归母净利润均为2.24亿元。

销售费用1.77亿元主要是渠道销售人员薪酬1.10亿元、宣传推广费0.17亿元、运杂费0.16亿元和折旧0.13亿元，反映新华书店与图书发行渠道的人员、宣传、物流和店面投入。管理费用2.82亿元主要是管理人员薪酬1.94亿元、折旧0.42亿元、取暖费0.12亿元、无形资产摊销0.10亿元；其中离职后福利为-0.22亿元，拉低了当期管理费用，但这不是经营效率永久改善。研发费用只有0.04亿元，主要对应数字出版、审校和技术服务投入。

投资收益0.01亿元和公允价值变动收益0.13亿元来自理财等金融资产，其他收益0.29亿元主要是政府补助。这些项目能改善当期净利润，但回本分母不能把它们都当作主业现金利润：定存和理财本金已经在折后净现金里扣掉，相关资金收益需要剔除或保守处理。

利润和现金流

2025年净利润2.24亿元、归母净利润2.24亿元、经营现金流3.30亿元，资本开支0.35亿元，经营自由现金流2.94亿元。经营现金流高于利润，主要不是赊账扩大，而是折旧摊销和营运资金释放：固定资产折旧0.81亿元、无形资产摊销0.10亿元、长期待摊摊销0.02亿元；存货减少0.13亿元，代表教材、图书和纸张库存净释放现金；经营性应收减少0.74亿元，代表客户欠款和往来款回收；经营性应付减少0.83亿元，则代表对供应商、员工、预收客户等占款减少，抵消了一部分现金流。

应收账款0.58亿元，只占收入的3.84%，账面赊销压力不大。存货1.80亿元，占收入11.89%，对出版公司仍需关注库龄和改版风险；年报披露出版和发行企业按库龄对库存出版物计提跌价准备，2025年存货跌价损失126.52万元，金额暂不大。合同负债2.24亿元，代表公司已经收或应收客户对价但尚未交付教材、图书或服务的义务，是教材征订模式下的经营缓冲。

行业位置和上下游

公司年报称出版业需要推进融合发展，龙版传媒也在做数字出版、AI审校和教育服务，但这些叙述只能代表公司视角。外部核查显示，传统出版发行的收入环境偏弱：国家新闻出版署《2024年新闻出版统计公报》（2025-12-18，https://www.nppa.gov.cn/xxgk/fdzdgknr/tjxx/202512/P020251218382424228218.pdf）披露，2024年全国图书出版营业收入1160.6亿元，同比下降2.7%，出版物发行营业收入3328.6亿元，同比下降3.2%；这支持“龙版传媒2025年收入下滑发生在行业承压背景下”的判断。

黑龙江省统计局《2025年黑龙江省国民经济和社会发展统计公报》（2026-03-31，https://tjj.hlj.gov.cn/tjj/c106779/202603/c00_31925539.shtml）披露，全省书报刊出版机构385个，出版图书10253万册、期刊1980万册、报纸25015万份；而《2023年黑龙江省国民经济和社会发展统计公报》（2024-06-11，https://tjj.hlj.gov.cn/tjj/c106779/202406/c00_31742252.shtml）披露当年书报刊出版机构398个、出版图书10993万册、期刊1996万册、报纸28861万份。这支持“本地区传统出版数量和机构基盘没有扩张，省内收入下降需要谨慎看待”的判断。

联合资信《2025年前三季度出版行业运行分析》（2025，https://www.lhratings.com/file/g0b9dd7dcaf.pdf）披露，2025年前三季度纸质图书市场码洋同比下降10.40%，实体渠道销售收入降幅仍较大，短视频电商是唯一正增长渠道。这支持“公司一般图书和零售渠道毛利承压，渠道转型会影响销售费用、库存和现金流”的判断。

上游主要是纸张、印刷服务、外购图书、作者稿酬和租型资源。公司没有披露对单一供应商严重依赖，成本表中发行外购图书7.58亿元、出版印刷费用3.38亿元、纸张费用0.62亿元，说明最大的成本压力在内容采购和印刷发行链条。下游主要是黑龙江省内学校征订、新华书店批发零售、团购和省外渠道。2025年省内收入11.26亿元，同比下降13.86%，毛利率47.32%；省外收入3.34亿元，同比增长12.77%，但毛利率只有18.23%，因此省外扩张对收入有帮助，对利润率未必友好。

投资和资本配置

2025年资本开支0.35亿元，主要包括门店升级改造0.11亿元、办公楼装修0.03亿元及其他长期资产购建。出版大厦项目本年从在建工程转入固定资产2.42亿元，年末固定资产达到21.51亿元，在建工程降到0.77亿元；这说明前期大项目已进入使用阶段，后续关键是资产能否带来更高坪效、办公效率或租售盘活，而不是继续大额建设。

资金配置上，公司仍以定存和理财沉淀现金：单位定期存款本金19.41亿元，交易性金融资产中的银行理财6.58亿元。投资活动现金流为-3.43亿元，主要因为购买理财6.50亿元、购买单位定存7.51亿元，同时收回理财5.33亿元和定存5.50亿元。融资现金流-0.67亿元，主要是现金分红。最近三个会计年度现金分红比例67.48%，说明公司有分红记录，但长期应付职工薪酬10.59亿元和教材教辅下滑会限制未来可分配弹性。

回本率和估值含义

owner_earnback公式为：经营业务购买价 = 市值 - 折后可剥离净现金；控股回本年数 = 经营业务购买价 / 折后可持续可分配现金利润。

本次复用结果：市值40.93亿元，折后可剥离净现金19.51亿元，经营业务购买价21.42亿元，折后可持续可分配现金利润1.21亿元，控股回本年数17.72年。控股回本率 = 1.21 / 21.42 = 5.64%；市值/折后现金利润 = 33.86年；现金利润收益率 = 1.21 / 40.93 = 2.95%。

这个回本数最依赖四个前提。第一，定存、理财可以按当前折扣作为可剥离资金，且2.50亿元必要经营现金足够覆盖教材发行季节性。第二，扣非利润扣除资金利息后的三年中位数1.51亿元能代表中期主业，再打0.80折得到1.21亿元。第三，长期应付职工薪酬不会突然要求大额提前支付。第四，教材教辅收入下滑不会继续加速。若第一项更保守，经营业务购买价会上升；若第二和第四项恶化，现金利润会下降，两者都会拉长回本期。

风险判断

教材教辅收入继续下降：高。 行业背景是教材教辅虽然刚需，但订单受学生人数、教材目录、征订政策影响。公司历史变化已经出现：2025年教材教辅收入10.29亿元，同比下降18.85%，教材教辅出版环节销售量下降33.20%，发行环节销售量下降9.62%。公司数字证据是教材教辅占主营收入70.46%，且毛利率49.04%，是利润核心。发生概率评为中，影响评为高；主观判断是这项最可能推翻回本分母，若继续下滑，1.21亿元折后现金利润仍可能偏高。

长期应付职工薪酬侵蚀现金归属：中。 行业背景是地方出版发行平台往往有历史人员和离退休福利义务。公司2025年长期应付职工薪酬10.59亿元，期初11.08亿元，本年已支付福利0.21亿元；折现率下降0.25个百分点会使义务现值增加0.64亿元。发生概率评为高，影响评为中；主观判断是它不等同于银行债务，但会消耗未来现金和分红弹性，因此不能把账上现金全部看成控股股东可自由拿走的钱。

资金可剥离低于折扣假设：中。 行业背景是国有出版公司资金可能服务募集资金项目、季节性备货和区域渠道稳定。公司年末单位定期存款本金19.41亿元、银行理财6.58亿元，受限资金552万元；年报未逐笔披露定存期限。发生概率评为中，影响评为中；主观判断是 owner_earnback 已经通过0.70/0.75折扣和2.50亿元必要经营现金处理，但若定存用途更刚性，折后净现金会下降，经营业务购买价会上升。该问题已查年报货币资金、受限资产、委托理财和募集资金附注，仍无法公开确认逐笔期限。

一般图书和零售渠道毛利承压：中。 行业背景是纸质图书市场和实体渠道承压，线上渠道结构变化使传统零售和电商促销常态化。公司2025年一般图书收入增长38.48%，但成本增长60.59%，毛利率降至19.30%；零售模式收入下降32.44%，毛利率下降9.58个百分点。发生概率评为中，影响评为中；主观判断是一般图书短期难以替代教材教辅成为高质量利润源，如果继续以低毛利收入填补规模，会拉低综合毛利率。

库存跌价和图书报废：中。 出版物有内容时效和改版风险，行业需求放缓时旧版、滞销和改版图书需要跌价或报废。公司2025年存货1.80亿元，同比下降6.91%，存货跌价损失126.52万元；一般图书出版环节库存量增长11.42%，印刷品库存量增长106.44%。发生概率评为中，影响评为低；主观判断是当前金额不大，但若一般图书和印刷业务需求判断失误，会通过跌价和报废侵蚀后续毛利。

已尝试但仍不可确认的事项只有两项：一是单位定期存款逐笔期限和用途，已查货币资金、受限资产、委托理财、募集资金使用和 owner_earnback 结果，公开年报未披露到逐笔层面；二是2026年以后教材教辅订单、学生人数和政策变化，已查年报、统计公报和行业资料，但这是未来事件。它们分别影响折后净现金和折后现金利润，是本报告结论的主要限制。
