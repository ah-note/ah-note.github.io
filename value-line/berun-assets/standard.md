# 通用型资产流转表

适用非金融、持续生产销售或提供服务的企业。设计由15份本地已完成报告交叉检验，博源再核对法定年报相关附注。不是15套年报的完整复审，不宣称所有混合金融集团已经适配。当前仅在独立网页原型使用，不修改研究Bundle、财报输入或生产队列。

## 结构

- 12个余额分类保留为计算桶，用于稳定映射、小计和闭合，不作为新版网页的主明细行。
- 新版主明细使用有限的具体经济对象字段，例如存货、客户应收款、房屋与经营场所、机器设备、在建工程、土地使用权、商誉、现金存款、投资及具体融资义务；对象按经营周转资本、长期经营资产、其他经营资产与义务、非经营资产、非经营负债分区。
- 13类经济变动：比讨论稿多一类“融资费用”，将本金和资金成本分开。
- 有方向的标准变动字段与资产正交；同一字段在不同资产行可以正负相反。
- `balance`：已核对余额差，但未证明经济原因；`unresolved`：附注未说明性质或未完整转录。两者是显式证据状态，不是万能“其他流转”。
- 默认展示具体经济对象；展开年度看标准变动对象及金额。公司特有原始科目、来源页码、推断和映射证据只在数据层或说明区。
- 零余额主项保留便于跨公司对照；无发生的变动不铺空白行。方向不同的事项不在明细中删除，即使类别净额为零。

## 余额字段边界

| 主项 | 含义与边界 |
| --- | --- |
| 经营周转净额 | 存货、经营债权、采购预付及经营结算义务；正常经营周期不机械等于一年。融资及明确异常拖欠剥离，不因负值推断竞争优势。 |
| 经营设施 | 自有/租入设施、在建项目、改造投入、持续生产用生物资产。待售产品不放这里。租赁使用权与融资付款义务同时保留，不混用旧报告经营租赁估值口径。 |
| 经营权利与开发资产 | 资源、土地、特许经营及已确认开发资产。费用化研发与品牌费用不虚构为资产；未来经济资本估计需要另层。 |
| 资本采购结算净额 | 购建设施及权利预付款，减正常资本采购欠款；非现金取得设施与付现购建不是同一数据。 |
| 商誉 | 保留账面值及实际减值，估值折价不能改写账面桥。 |
| 其他经营净额 | 经营税项、已确认补助余额、复垦及员工等义务；不得容纳主要经营资产。 |
| 现金与存款 | 现金、定期存款及保证金分项保留可用性；未估计必要现金时必须注释，不能用于直接计算可分配现金。 |
| 对外投资 | 未并表企业投资、证券与投资工具。取得控制后变为并表经营资产，不重复留投资余额。 |
| 其他非经营资产 | 非核心出租资产、投资应收、融资递延费用等；主营出租物业仍属经营。 |
| 融资负债 | 借款、债券、租赁及实质融资采购款，保留本金/利息/混合口径。 |
| 股东相关应付款 | 已宣告未支付股利、已确认回购或赎回义务。股权激励费用、库存股和现金回购不得当成相同事项。 |
| 其他非经营负债 | 投资相关义务及已查实的异常拖欠等。少数股东权益不在这里。 |

集团内金融业务若重大，不能硬塞入通用周转或其他资产。先并列保留金融子业务资产负债明细，必要时另用专用模板；这是通用型范围限制，不以集团主分类强行豁免。

## 数据与核对

原始 `data.json` 不变；`evidence.js` 补现金拆分、出租物业变动及非现金投资，替代项逐元闭合原记录。`mapping.js` 只做有来源的分拆与重分类，不拟合新余额。每个原始余额按 origin 核对完整、无重复；各层均期初+变动=期末。

博源其他经营净额中的土地欠款移入资本采购结算，资本预付中的税款移到其他经营净额；均保持经营净资产总量。现金桥不宣称已经与所有资产行逐交易配对，现有披露不足部分保留差额/余额标记。未来需要源事实ID才能做完整双边交易图，不在本原型虚构这一能力。

## 增补准入

主要资产或变动被“其他”吞没、出现重复经济机制且影响比较时，调整标准字段。公司特有措辞只进事项层。模板不能替代证据；无资料不编成精准收付，允许可追溯估计但必须与事实分开。
