# 博源化工资产变动试表

入口 `/value-line/berun-assets/`。2024 年末—2025 年变动—2025 年末，合并口径。

`data.json` 登记本页数据与来源：余额和附注变动以人民币元保存，渲染为亿元。来源 URL、印刷页在数据中保留。三类总量由子项重分类计算，不是年报原有指标。必要经营现金尚未划分、投资与票据融资等分类边界见 notes.html。

残余变动显式标为 residual，不能当作已解释事实；股票报告、生产队列和原型其他页面不受影响。本地预览，未公开部署。

验证：`node --test tests/test_berun_assets.js`。验证逐项变动、组内汇总、合并及归母净资产。无依赖安装或构建步骤。

通用型字段规范与15公司检验见 `standard.md`。`fields.js` 固定12个余额主项、13类经济变动及有方向的标准字段。余额变化/未解释差额是独立证据状态，不充当经济原因。

`evidence.js` 保存博源年报增量转录；`mapping.js` 核对替代变动、资本采购税款和土地欠款的重分类及周转构成。原始 data.json 不变，每个原始余额按 origin 无重叠核对。现金按经营、购建、投资、融资费用和股东交易重构，不直接展示法定三类现金流。

原生 details/summary 提供资产构成、标准变动及公司事项三层展开，主表不显示年报页码与工作状态段落；来源与应付性质限制集中在 notes.html。融资本息、受限资金、必要现金及部分非现金原因仍有披露限制，不能视为完整逐交易匹配。通用模板不能直接处理重大金融子业务。
