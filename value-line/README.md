# 公司数据页试阅 01

独立静态原型，不修改现有报告或队列。入口 `/value-line/`。

## 数据登记

- 快照时间：2026-09-09，Asia/Shanghai。
- 来源：已公开的 AH Note 600585.SH、600801.SH、002233.SZ 的 2025 年经营研究结构化成果。
- 覆盖：2023—2025。`data.json` 保留原字段数值、来源文件、页码和原成果 SHA-256。
- 展示收入、成本、归母利润、经营现金流、购建长期资产现金支出；毛利率沿用并核算收入与成本。
- 现金余额指标为 OCF 减购建长期资产支付现金，不是 FCFF，也不是旧报告净资本开支口径。
- 每股视图统一采用各公司底稿 2025 年估值股数，不能当成历史财报 EPS 或据此判断摊薄。
- 塔牌归母利润在本次所取底稿事实中未收录，保留 null，不能填零。
- 十年历史、股价、实际 EPS、分红回购尚未接入，不用模拟数据补齐。
- 研究估计独立折叠，与历史事实隔离；原报告口径与版本保持不变。
