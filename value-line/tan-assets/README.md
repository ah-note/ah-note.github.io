# 谭木匠资产流转试表

入口 `/value-line/tan-assets/`，2024年末至2025年末。与博源共享 `../berun-assets/fields.js`、`app.js`、`style.css`，没有复制第二套标准字段或显示算法。`mapping.js`按标准资产ID分配组件、校验逐行与各类总额；`data.json`保存人民币元数据、来源页、证据模式、PDF哈希。

来源：港交所2026-04-17公布2025年年报，URL及SHA256在数据中。复用本地00837.HK报告定位，不直接照搬其估值折价及经营租赁口径。年报单位千元，本表乘1000。取舍与年报内部不一致见notes.html。

通用字典新增 `operating_net`（经营收付净额），用于只披露间接法现金流、不能取得收付总额的公司；不得冒充收到经营款。总经济变动类别仍为13。小于100万元的数字最多显示5位亿元小数，避免1000元差异显示成0.00。

资本采购结算暂按零估计，可能混入经营预付及往来；显式标记估计，不宣称原始披露为零。股份、商誉和少数权益按已识别披露处理。未知资产变动保留差额，不构造假交易。

资本活动在同页下方，四列为大项目、净贡献或净收付、子项目、金额，无期初期末。`activities.json`保存年报千元输入及来源；`activities.js`计算并校验净利润、净资产增量、现金与全部存款增量。净资产形成与资金配置分别闭合，不混加。税项按公司实际税负比例分摊，显式估计；费用中的折旧与资产损失单列，不对成本和期间费用的折旧进行虚假细分。范围和边界见notes.html。

测试：`node --test tests/test_tan_assets.js tests/test_berun_assets.js tests/test_tan_activities.js`。独立本地原型，未公开部署，不影响分析或发布队列。
